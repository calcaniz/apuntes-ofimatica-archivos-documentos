    S02.02 (14/10/2026)

    En la sesión anterior repasamos las partes de una tabla y recordamos cómo insertar una tabla sencilla.

    En esta sesión aprenderemos a modificar su estructura: añadiremos y eliminaremos filas y columnas, cambiaremos su tamaño y uniremos algunas celdas.

    ¿Qué vamos a hacer hoy?

    Vamos a:

    • Crear una tabla con las filas y columnas indicadas;
    • Añadir nuevas filas;
    • Añadir nuevas columnas;
    • Eliminar filas y columnas innecesarias;
    • Cambiar el ancho de las columnas;
    • Cambiar la altura de las filas;
    • Unir varias celdas;
    • Introducir correctamente la información.

    ¿Qué debemos recordar?

    Una tabla está formada por:

    • Filas, que se distribuyen horizontalmente;
    • Columnas, que se distribuyen verticalmente;
    • Celdas, que contienen la información;
    • Encabezados, que explican qué datos aparecen en cada columna.

    Antes de modificar una fila, una columna o una celda debemos seleccionarla.

    ¿Qué criterio vamos a trabajar?

    • CE03-e: trabajar con tablas y elaborar documentos con exactitud, aplicando los formatos indicados.

    1. Pensar antes de crear la tabla

    Antes de insertar una tabla debemos decidir:

    1. Qué información queremos representar.
    2. Cuántas columnas necesitamos.
    3. Qué encabezado tendrá cada columna.
    4. Cuántas filas de datos vamos a utilizar.

    Por ejemplo, para organizar las actividades de un evento podemos utilizar:

    Actividad Lugar Día Hora
    Presentación Salón principal Viernes 16:00
    Competición Pista central Viernes 17:00
    Entrega de premios Escenario Viernes 19:00

    Esta tabla tiene:

    • Cuatro columnas;
    • Cuatro filas;
    • Una fila de encabezados;
    • Tres filas de datos.

    La fila de encabezados también cuenta cuando calculamos el número total de filas.

    2. Crear una tabla

    Para insertar una tabla utilizamos:

    Taula → Insereix taula

    También podemos utilizar el botón de tabla de la barra de herramientas.

    En la ventana que aparece indicamos:

    • El número de columnas;
    • El número de filas.

    Ejemplo

    Si necesitamos:

    • Una fila de encabezados;
    • Cuatro filas de información;
    • Cinco datos en cada fila;

    Crearemos una tabla de:

    • Cinco filas;
    • Cinco columnas.

    3. Desplazarnos por las celdas

    Para escribir en una celda hacemos clic dentro de ella.

    Podemos pasar a la siguiente celda utilizando la tecla:

    Tabulador

    Para volver a la celda anterior podemos utilizar:

    Mayúsc + Tabulador

    También podemos movernos haciendo clic directamente en la celda que necesitamos.

    Añadir rápidamente una fila

    Si colocamos el cursor en la última celda de la tabla y pulsamos Tabulador, Writer puede crear una nueva fila automáticamente.

    Esta opción es útil cuando necesitamos introducir un dato adicional.

    4. Seleccionar una fila

    Para modificar una fila completa debemos seleccionarla.

    Podemos hacerlo:

    1. Colocando el cursor dentro de una de sus celdas.
    2. Accediendo a las opciones de selección de la tabla.
    3. Seleccionando la fila completa.

    También podemos utilizar el botón derecho del ratón y buscar las opciones relacionadas con las filas.

    Cuando una fila está seleccionada podemos:

    • Añadir otra fila;
    • Eliminarla;
    • Cambiar su altura;
    • Aplicar un formato común a todas sus celdas.

    5. Añadir una fila

    Podemos añadir una fila:

    • Encima de la fila seleccionada;
    • Debajo de la fila seleccionada;
    • Al final de la tabla.

    Podemos utilizar el menú Taula o pulsar con el botón derecho dentro de la tabla.

    Según la versión de Writer, encontraremos opciones parecidas a:

    • Insereix -> files a sobre;
    • Insereix -> files a sota;

    Después de añadirla debemos introducir los datos correspondientes.

    6. Eliminar una fila

    Para eliminar una fila:

    1. Colocamos el cursor dentro de la fila.
    2. Pulsamos con el botón derecho.
    3. Elegimos la opción para eliminar filas.

    También podemos utilizar el menú:

    Taula → Suprimeix → Files

    Borrar el texto de las celdas no elimina la fila. Solamente elimina su contenido.

    7. Añadir una columna

    Podemos añadir una columna:

    • A la izquierda de la columna seleccionada;
    • A la derecha de la columna seleccionada.

    Para hacerlo podemos utilizar:

    • El menú Tabla;
    • El botón derecho del ratón;
    • Los botones de la barra de herramientas de tablas.

    Después debemos añadir un encabezado y completar los datos de la nueva columna.

    Ejemplo

    Tenemos esta tabla:

    Participante Hora
    Ana 17:00
    David 17:15

    Si añadimos una columna llamada Categoría, quedaría así:

    Participante Categoría Hora
    Ana Iniciación 17:00
    David Avanzada 17:15

    8. Eliminar una columna

    Para eliminar una columna:

    1. Colocamos el cursor dentro de una de sus celdas.
    2. Seleccionamos la columna.
    3. Utilizamos la opción Suprimeix -> Columnes.

    Debemos comprobar que la columna no contenga información necesaria.

    Antes de eliminar una fila o una columna conviene revisar todos sus datos.

    Si nos equivocamos podemos deshacer la última acción utilizando:

    Ctrl + Z

    9. Cambiar el ancho de una columna

    No todas las columnas necesitan el mismo espacio.

    Por ejemplo:

    • Una columna con nombres puede ser ancha;
    • Una columna con horas puede ser estrecha;
    • Una columna con descripciones necesita más espacio.

    Para cambiar el ancho:

    1. Colocamos el ratón sobre la línea que separa dos columnas.
    2. Esperamos a que cambie la forma del puntero.
    3. Arrastramos la línea hacia la izquierda o hacia la derecha.

    Debemos evitar que:

    • El texto quede cortado;
    • Las palabras ocupen demasiadas líneas;
    • La tabla sobrepase los márgenes de la página.

    10. Cambiar la altura de una fila

    La altura puede modificarse colocando el ratón sobre el borde inferior de la fila y arrastrándolo.

    Normalmente Writer adapta automáticamente la altura al contenido.

    Solo debemos aumentarla cuando:

    • El texto esté demasiado junto;
    • Necesitemos más espacio;
    • Queramos mejorar la presentación.

    No debemos crear espacio dentro de una tabla pulsando muchas veces la tecla Intro.

    11. Unir celdas

    Unir celdas significa convertir varias celdas en una sola.

    Esta opción puede utilizarse para crear un título que ocupe todo el ancho de la tabla.

    Ejemplo

    Podemos unir las celdas de la primera fila para escribir:

    PROGRAMA DEL EVENTO

    Para unirlas:

    1. Seleccionamos las celdas.
    2. Utilizamos la opción Fusiona les cel·les.

    Podemos encontrar esta opción:

    • en el menú Taula;
    • en la barra de herramientas;
    • pulsando con el botón derecho.

    Solo debemos unir celdas cuando ayude a organizar la información.

    12. Separar una celda

    Una celda también puede dividirse en varias partes.

    Para hacerlo:

    1. Seleccionamos la celda.
    2. Elegimos Divideix les cel·les.
    3. Indicamos el número de partes que necesitamos.

    Esta opción puede utilizarse cuando necesitamos añadir más información dentro de una zona de la tabla.

    Para esta sesión utilizaremos principalmente la opción de Fusiona cel·les.
