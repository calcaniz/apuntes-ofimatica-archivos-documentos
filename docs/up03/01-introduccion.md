### 1.3. Mapa de criterios de evaluación

| CE { .table-main-column .table-content .table-bg-principal .table-cl-secundario } | Descripción { .table-full-container .table-content .table-bg-principal .table-cl-secundario } |
|---|---|
| CE06-a { .table-cl-secundario .table-text-bold } | Identificación de los componentes principales de los equipos y de sus necesidades básicas de mantenimiento, utilizando los manuales de uso y los sistemas de ayuda. |
| CE06-b { .table-cl-secundario .table-text-bold } | Descripción del funcionamiento de fotocopiadoras, impresoras, escáneres, reproductoras, perforadoras, encuadernadoras y otros equipos. |
| CE06-c { .table-cl-secundario .table-text-bold } | Identificación de las incidencias básicas que pueden aparecer en los equipos de reproducción e informáticos y de las posibles actuaciones para resolverlas. |
| CE06-d { .table-cl-secundario .table-text-bold } | Realización de las tareas básicas de limpieza y mantenimiento de los equipos y útiles utilizados. |
| CE06-e { .table-cl-secundario .table-text-bold } | Realización de los ajustes necesarios para garantizar el funcionamiento adecuado de los equipos. |
| CE06-f { .table-cl-secundario .table-text-bold } | Identificación de los consumibles —papel, tinta, tóner, cartuchos, cintas y otros— y relación de cada uno con el equipo correspondiente. |
| CE06-g { .table-cl-secundario .table-text-bold } | Manejo responsable de los equipos, evitando costes, consumos y desgastes innecesarios. |
| CE06-h { .table-cl-secundario .table-text-bold } | Puesta a punto de los equipos, resolución de incidencias sencillas, sustitución de consumibles y aplicación de las medidas de seguridad necesarias. |
