# La impresora

Una **impresora** es un periférico de salida que permite reproducir sobre papel textos, imágenes, gráficos y otros documentos almacenados en formato digital.

Puede conectarse directamente a un ordenador o compartirse entre varios equipos mediante una red.

## Formas de conexión

Una impresora puede recibir los documentos mediante diferentes conexiones:

| Conexión { .table-main-column .table-content .table-bg-principal .table-cl-secundario } | Características { .table-full-container .table-content .table-bg-principal .table-cl-secundario } |
|---|---|
| **USB** { .table-cl-secundario .table-text-bold } | Conecta directamente la impresora con un ordenador mediante un cable. |
| **Ethernet** { .table-cl-secundario .table-text-bold } | Conecta la impresora a una red mediante un cable con conector RJ45. |
| **Wifi** { .table-cl-secundario .table-text-bold } | Permite imprimir desde diferentes dispositivos sin utilizar cables. |
| **Bluetooth** { .table-cl-secundario .table-text-bold } | Permite una conexión inalámbrica entre dispositivos cercanos. |
| **Memoria USB o tarjeta** { .table-cl-secundario .table-text-bold } | Algunos modelos pueden imprimir archivos sin utilizar un ordenador. |
| **Puerto paralelo** { .table-cl-secundario .table-text-bold } | Conexión utilizada en impresoras antiguas y actualmente en desuso. |

Para utilizar una impresora, el sistema operativo debe reconocerla y disponer del **controlador** adecuado.

El controlador, también llamado *driver*, es el programa que permite la comunicación entre el ordenador y la impresora.

## Criterios para elegir una impresora

Antes de elegir una impresora debemos pensar qué trabajos vamos a realizar y con qué frecuencia la utilizaremos.

| Criterio { .table-main-column .table-content .table-bg-principal .table-cl-secundario } | Explicación { .table-full-container .table-content .table-bg-principal .table-cl-secundario } |
|---|---|
| **Tecnología** { .table-cl-secundario .table-text-bold } | Puede ser de inyección de tinta, láser, térmica u otra tecnología. |
| **Color** { .table-cl-secundario .table-text-bold } | Puede imprimir solamente en blanco y negro o también en color. |
| **Velocidad** { .table-cl-secundario .table-text-bold } | Indica el número de páginas que puede imprimir por minuto. Se expresa en ppm. |
| **Resolución** { .table-cl-secundario .table-text-bold } | Indica el nivel de detalle de la impresión. Se mide en puntos por pulgada o ppp. |
| **Conexiones** { .table-cl-secundario .table-text-bold } | Debemos comprobar si dispone de USB, Ethernet, wifi u otras conexiones. |
| **Tamaño del papel** { .table-cl-secundario .table-text-bold } | Algunos modelos solo imprimen en A4 y otros permiten utilizar A3 u otros formatos. |
| **Doble cara** { .table-cl-secundario .table-text-bold } | Permite imprimir automáticamente por las dos caras del papel. |
| **Coste de los consumibles** { .table-cl-secundario .table-text-bold } | Hay que valorar el precio de los cartuchos, del tóner y del resto de materiales. |
| **Cantidad de impresiones** { .table-cl-secundario .table-text-bold } | Una impresora doméstica y una impresora de oficina no están preparadas para el mismo volumen de trabajo. |

!!! nota
    Una impresora barata puede resultar cara si sus cartuchos tienen poca capacidad o un precio elevado.

## Tipos de impresoras más habituales

### Impresora de inyección de tinta

Proyecta pequeñas gotas de tinta sobre el papel.

Sus principales características son:

- Tiene un precio inicial relativamente bajo.

- Puede imprimir en blanco y negro y en color.

- Ofrece buenos resultados en documentos e imágenes.

- Utiliza cartuchos de tinta.

- Es habitual en viviendas, pequeños comercios y oficinas.

### Impresora láser

Utiliza tóner en polvo para formar la imagen sobre el papel.

Sus principales características son:

- Imprime con rapidez.

- Produce textos de buena calidad.

- Es adecuada para imprimir muchos documentos.

- Suele tener un coste por página reducido.

- Puede ser monocromática o en color.

- Es habitual en centros educativos, empresas y oficinas.

### Plóter

Es una impresora preparada para trabajar con documentos de gran tamaño.

Se utiliza principalmente para imprimir:

- Planos.

- Carteles.

- Diseños técnicos.

- Proyectos de arquitectura.

- Publicidad de gran formato.

### Impresora térmica

Utiliza calor para formar la imagen sobre un papel especial.

Es habitual en:

- Cajas registradoras.

- Cajeros automáticos.

- Impresión de tiques.

- Etiquetas.

El texto puede desaparecer con el paso del tiempo o si el papel se expone a una temperatura elevada.

### Impresora 3D

Permite crear objetos con volumen a partir de un diseño realizado con un programa informático.

Puede utilizar materiales como:

- Plásticos.

- Resinas.

- Metales.

- Otros materiales especiales.

Se emplea en la industria, la medicina, la educación, la arquitectura y el diseño.

### Impresora virtual

Una impresora virtual no es una máquina física. Es un programa que aparece en el sistema como si fuera una impresora.

Permite convertir un documento en un archivo, por ejemplo:

- PDF.

- Imagen.

- Otros formatos digitales.

En LliureX, la opción **Imprimir en un archivo** permite generar un documento PDF sin utilizar papel.

## Otras tecnologías de impresión

Existen impresoras especializadas para trabajos concretos:

| Tecnología { .table-main-column .table-content .table-bg-principal .table-cl-secundario } | Utilización { .table-full-container .table-content .table-bg-principal .table-cl-secundario } |
|---|---|
| **Sublimación** { .table-cl-secundario .table-text-bold } | Produce fotografías de gran calidad utilizando calor y tintas especiales. |
| **Zink** { .table-cl-secundario .table-text-bold } | Utiliza un papel especial que contiene los colores necesarios para formar la imagen. |
| **Tinta sólida** { .table-cl-secundario .table-text-bold } | Emplea bloques o barras de tinta que se derriten durante la impresión. |
| **Impacto** { .table-cl-secundario .table-text-bold } | Golpea una cinta entintada contra el papel. Es una tecnología antigua que todavía se utiliza en algunos trabajos administrativos. |

## Tipos de papel

No todos los papeles son adecuados para todas las impresoras.

Antes de imprimir debemos comprobar:

- El tamaño del papel.

- El gramaje.

- La textura.

- El acabado mate o brillante.

- La compatibilidad con la impresora.

- El tipo de trabajo que vamos a realizar.

El **gramaje** indica el peso y el grosor aproximado del papel. Se expresa en gramos por metro cuadrado: **g/m²**.

El papel habitual de oficina suele tener un gramaje de **80 g/m²**.

| Tipo de papel { .table-main-column .table-content .table-bg-principal .table-cl-secundario } | Utilización { .table-full-container .table-content .table-bg-principal .table-cl-secundario } |
|---|---|
| **Offset** { .table-cl-secundario .table-text-bold } | Es el papel habitual para imprimir documentos. Es poroso y absorbe bien la tinta. |
| **Satinado o fotográfico** { .table-cl-secundario .table-text-bold } | Tiene un acabado suave o brillante y mejora la impresión de fotografías. |
| **Kraft** { .table-cl-secundario .table-text-bold } | Es resistente y se utiliza en embalajes, tarjetas, invitaciones y carteles. |
| **Verjurado** { .table-cl-secundario .table-text-bold } | Tiene una textura marcada y se utiliza en documentos, diplomas e invitaciones. |
| **Adhesivo** { .table-cl-secundario .table-text-bold } | Se utiliza para imprimir etiquetas y pegatinas. |
| **Especial** { .table-cl-secundario .table-text-bold } | Puede tener colores, decoraciones, texturas o un gramaje elevado. |

!!! warning "Antes de utilizar un papel especial"
    Comprueba en el manual que el papel sea compatible con la impresora. Un papel demasiado grueso, húmedo, arrugado o perforado puede provocar un atasco.

## Página de prueba

Después de instalar o configurar una impresora, es recomendable imprimir una **página de prueba**.

Esta página permite comprobar:

- Que el ordenador se comunica con la impresora.

- Que el controlador está instalado.

- Que la tinta o el tóner funcionan correctamente.

- Que el papel está bien colocado.

- Que la impresión tiene una calidad adecuada.

### Imprimir una página de prueba en LliureX

El nombre de las opciones puede cambiar según la versión, pero el procedimiento habitual es:

1. Abre la **Configuración del sistema**.

2. Entra en el apartado **Impresoras**.

3. Selecciona la impresora instalada.

4. Abre sus propiedades u opciones.

5. Selecciona **Imprimir página de prueba**.

También es posible imprimir una página de prueba desde el panel de control de algunos modelos.

## Incidencias frecuentes

Antes de intentar solucionar una incidencia, debemos leer el mensaje que aparece en el ordenador o en el panel de la impresora.

| Problema { .table-main-column .table-content .table-bg-principal .table-cl-secundario } | Posible causa { .table-content .table-bg-principal .table-cl-secundario } | Actuación { .table-full-container .table-content .table-bg-principal .table-cl-secundario } |
|---|---|---|
| **La impresora no imprime** { .table-cl-secundario .table-text-bold } | Está apagada, desconectada o no está seleccionada. | Comprobar la alimentación, la conexión y la impresora seleccionada. |
| **El documento queda en espera** { .table-cl-secundario .table-text-bold } | Existe un problema en la cola de impresión. | Abrir la cola, comprobar el trabajo y cancelar los documentos bloqueados. |
| **Atasco de papel** { .table-cl-secundario .table-text-bold } | El papel está doblado, mal colocado o la bandeja está demasiado llena. | Seguir las indicaciones del equipo y retirar el papel con cuidado. |
| **Impresión de baja calidad** { .table-cl-secundario .table-text-bold } | La configuración no es adecuada o queda poca tinta o tóner. | Revisar la calidad seleccionada y comprobar los consumibles. |
| **Colores incorrectos** { .table-cl-secundario .table-text-bold } | Algún cartucho está vacío, sucio o mal colocado. | Comprobar los cartuchos y realizar una prueba de impresión. |
| **Líneas blancas** { .table-cl-secundario .table-text-bold } | Los cartuchos están sucios o el tóner se está agotando. | Ejecutar la limpieza recomendada o sustituir el consumible. |
| **Aparecen manchas** { .table-cl-secundario .table-text-bold } | El interior está sucio o el papel no es adecuado. | Detener la impresión y comunicar la incidencia. |
| **La impresión aparece cortada** { .table-cl-secundario .table-text-bold } | El tamaño, la orientación o los márgenes no son correctos. | Revisar la configuración de la página y del papel. |
| **La impresora produce mal olor** { .table-cl-secundario .table-text-bold } | Puede existir un problema con el tóner o un componente interno. | Apagar la impresora y avisar inmediatamente al responsable. |
| **No hay comunicación** { .table-cl-secundario .table-text-bold } | El cable está desconectado o existe un problema de red. | Comprobar la conexión y el estado de la impresora. |

!!! danger "Seguridad"
    No introduzcas objetos en la impresora ni toques las zonas internas que puedan estar calientes. Si una incidencia no se resuelve con una comprobación sencilla, apaga el equipo y avisa al profesor o a la persona responsable.
