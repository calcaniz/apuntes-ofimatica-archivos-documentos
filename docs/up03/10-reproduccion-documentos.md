# Reproducción de documentos

La **reproducción de documentos** consiste en obtener una o varias copias de un original mediante una fotocopiadora, una impresora, un escáner u otro equipo.

Antes de utilizar cualquier equipo debemos:

1. Conocer su funcionamiento básico.

2. Comprobar que está preparado.

3. Seleccionar los materiales adecuados.

4. Configurar correctamente las opciones.

5. Realizar una prueba.

6. Comprobar la calidad del resultado.

7. Corregir los errores antes de realizar todas las copias.

Los fabricantes proporcionan manuales con información sobre la instalación, la utilización, el mantenimiento y la resolución de incidencias.

## Calidad en la reprografía

La **calidad** de una reproducción depende del equipo, de los materiales, de la configuración seleccionada y de la persona que realiza el trabajo.

Una reproducción de calidad debe cumplir estas condiciones:

- El contenido aparece completo.

- El texto puede leerse correctamente.

- Las imágenes tienen suficiente claridad.

- El documento está bien centrado.

- El papel tiene el tamaño adecuado.

- No aparecen manchas, rayas ni zonas borrosas.

- Los colores son correctos.

- Se ha obtenido el número de copias solicitado.

## Calidad de una fotocopia

Para obtener una buena fotocopia debemos comprobar:

| Comprobación { .table-main-column .table-content .table-bg-principal .table-cl-secundario } | Actuación { .table-full-container .table-content .table-bg-principal .table-cl-secundario } |
|---|---|
| **Colocación del original** { .table-cl-secundario .table-text-bold } | Alinear correctamente el documento sobre el cristal o en el alimentador. |
| **Tamaño del papel** { .table-cl-secundario .table-text-bold } | Seleccionar un tamaño adecuado al original. |
| **Orientación** { .table-cl-secundario .table-text-bold } | Elegir orientación vertical u horizontal según el documento. |
| **Claridad** { .table-cl-secundario .table-text-bold } | Ajustar la densidad si la copia aparece demasiado clara u oscura. |
| **Estado del cristal** { .table-cl-secundario .table-text-bold } | Comprobar que no tenga polvo, manchas o restos de papel. |
| **Consumibles** { .table-cl-secundario .table-text-bold } | Utilizar papel y tóner compatibles con la máquina. |
| **Número de páginas** { .table-cl-secundario .table-text-bold } | Comprobar que se han copiado todas las páginas necesarias. |

## Calidad de una impresión

Para obtener una impresión adecuada debemos revisar:

| Comprobación { .table-main-column .table-content .table-bg-principal .table-cl-secundario } | Actuación { .table-full-container .table-content .table-bg-principal .table-cl-secundario } |
|---|---|
| **Resolución** { .table-cl-secundario .table-text-bold } | Seleccionar una calidad adecuada al tipo de documento. |
| **Modo de impresión** { .table-cl-secundario .table-text-bold } | Elegir entre borrador, normal o alta calidad. |
| **Tinta o tóner** { .table-cl-secundario .table-text-bold } | Comprobar que queda suficiente consumible. |
| **Color** { .table-cl-secundario .table-text-bold } | Elegir blanco y negro, escala de grises o color. |
| **Papel** { .table-cl-secundario .table-text-bold } | Utilizar un papel compatible con el equipo y con el trabajo. |
| **Orientación y márgenes** { .table-cl-secundario .table-text-bold } | Comprobar la vista previa antes de imprimir. |
| **Cabezales** { .table-cl-secundario .table-text-bold } | Realizar su alineación o limpieza cuando sea necesario. |

No debemos agotar completamente los cartuchos. Cuando queda poca tinta, los colores pueden aparecer apagados o pueden producirse líneas y zonas sin imprimir.

## Calidad de un escaneo

Para obtener un archivo digital de buena calidad debemos comprobar:

| Comprobación { .table-main-column .table-content .table-bg-principal .table-cl-secundario } | Actuación { .table-full-container .table-content .table-bg-principal .table-cl-secundario } |
|---|---|
| **Limpieza del cristal** { .table-cl-secundario .table-text-bold } | Eliminar el polvo y las manchas con el procedimiento adecuado. |
| **Colocación del original** { .table-cl-secundario .table-text-bold } | Alinear el documento para evitar que aparezca torcido. |
| **Resolución** { .table-cl-secundario .table-text-bold } | Utilizar normalmente entre 200 y 300 ppp para documentos. |
| **Modo de color** { .table-cl-secundario .table-text-bold } | Elegir color, escala de grises o blanco y negro. |
| **Formato** { .table-cl-secundario .table-text-bold } | Utilizar PDF para documentos y JPG o PNG para imágenes. |
| **Tamaño del documento** { .table-cl-secundario .table-text-bold } | Seleccionar el área necesaria para no guardar bordes innecesarios. |
| **Vista previa** { .table-cl-secundario .table-text-bold } | Comprobar el resultado antes de guardar el archivo. |

## Parámetros de reproducción

Los **parámetros** son las opciones que podemos modificar antes de reproducir un documento.

No todos los equipos permiten configurar las mismas opciones.

| Parámetro { .table-main-column .table-content .table-bg-principal .table-cl-secundario } | Posibilidades { .table-full-container .table-content .table-bg-principal .table-cl-secundario } |
|---|---|
| **Tamaño del papel** { .table-cl-secundario .table-text-bold } | A3, A4, A5 u otros formatos. |
| **Gramaje** { .table-cl-secundario .table-text-bold } | Papel normal, cartulina, papel fotográfico u otros. |
| **Orientación** { .table-cl-secundario .table-text-bold } | Vertical u horizontal. |
| **Número de copias** { .table-cl-secundario .table-text-bold } | Cantidad de ejemplares que se van a obtener. |
| **Páginas** { .table-cl-secundario .table-text-bold } | Todas las páginas, una página concreta o un intervalo. |
| **Caras** { .table-cl-secundario .table-text-bold } | Una cara o doble cara. |
| **Color** { .table-cl-secundario .table-text-bold } | Blanco y negro, escala de grises o color. |
| **Calidad** { .table-cl-secundario .table-text-bold } | Borrador, normal o alta calidad. |
| **Brillo** { .table-cl-secundario .table-text-bold } | Permite aclarar u oscurecer el resultado. |
| **Contraste** { .table-cl-secundario .table-text-bold } | Aumenta o reduce la diferencia entre las zonas claras y oscuras. |
| **Escala** { .table-cl-secundario .table-text-bold } | Tamaño real, ampliación o reducción. |
| **Páginas por hoja** { .table-cl-secundario .table-text-bold } | Permite colocar varias páginas del documento en una sola hoja. |
| **Clasificación** { .table-cl-secundario .table-text-bold } | Ordena las copias cuando se imprimen documentos de varias páginas. |
| **Grapado** { .table-cl-secundario .table-text-bold } | Une automáticamente las hojas si el equipo dispone de esta función. |

## Páginas por hoja

La opción **páginas por hoja** permite colocar varias páginas del documento en una única cara del papel.

Por ejemplo:

- Dos páginas en una hoja.

- Cuatro páginas en una hoja.

- Seis páginas en una hoja.

Esta opción permite ahorrar papel, pero reduce el tamaño del contenido.

Antes de utilizarla debemos comprobar que el texto continúa siendo legible.

## Impresión a doble cara

La impresión a doble cara permite utilizar las dos caras de una hoja.

Puede realizarse:

- **Automáticamente**, si la impresora dispone de esta función.

- **Manualmente**, volviendo a introducir las hojas en la bandeja.

!!! warning
    La impresión manual a doble cara debe realizarse con cuidado. Si el papel se coloca en una posición incorrecta, la segunda cara puede aparecer al revés.

## La copia de prueba

Antes de realizar muchas copias es recomendable obtener una **copia de prueba**.

La copia de prueba permite comprobar:

1. El tamaño y la orientación.

2. Los márgenes.

3. La posición del contenido.

4. La claridad del texto.

5. La calidad de las imágenes.

6. Los colores.

7. El orden de las páginas.

8. La configuración a una o doble cara.

Si el resultado es incorrecto, debemos modificar los parámetros y repetir la prueba.

!!! importante "Evita el desperdicio"
    No debemos realizar toda la tirada sin revisar una primera copia. Un error de configuración puede provocar el desperdicio de mucho papel, tinta y tóner.

## Proceso correcto de reproducción

Para realizar un trabajo de reproducción seguiremos este orden:

1. Leer las instrucciones del encargo.

2. Revisar el documento original.

3. Elegir el equipo adecuado.

4. Seleccionar el papel y los consumibles.

5. Configurar los parámetros.

6. Utilizar la vista previa.

7. Realizar una copia de prueba.

8. Comprobar la calidad.

9. Corregir los errores.

10. Realizar el resto de las copias.

11. Recoger y ordenar el trabajo.

12. Dejar el equipo preparado para la siguiente persona.

## Ajustes durante la reproducción

Después de realizar la prueba pueden aparecer errores que requieren modificar la configuración.

| Error { .table-main-column .table-content .table-bg-principal .table-cl-secundario } | Posible causa { .table-content .table-bg-principal .table-cl-secundario } | Ajuste necesario { .table-full-container .table-content .table-bg-principal .table-cl-secundario } |
|---|---|---|
| **Falta una parte del original** { .table-cl-secundario .table-text-bold } | El documento está mal colocado o el papel seleccionado es demasiado pequeño. | Colocar correctamente el original y revisar el tamaño del papel. |
| **La copia sale demasiado oscura** { .table-cl-secundario .table-text-bold } | El nivel de brillo o densidad no es adecuado. | Aclarar la copia o reducir la densidad. |
| **La copia sale demasiado clara** { .table-cl-secundario .table-text-bold } | El nivel de brillo es demasiado alto o queda poco consumible. | Oscurecer la copia y comprobar la tinta o el tóner. |
| **Aparecen manchas** { .table-cl-secundario .table-text-bold } | El cristal o alguna parte del equipo está sucia. | Detener el trabajo y realizar la limpieza autorizada. |
| **El resultado está borroso** { .table-cl-secundario .table-text-bold } | La resolución es baja o el original no está bien colocado. | Revisar la resolución y la posición del documento. |
| **La imagen aparece torcida** { .table-cl-secundario .table-text-bold } | El original o el papel están mal alineados. | Colocar correctamente el documento y ajustar las guías. |
| **Los colores no son correctos** { .table-cl-secundario .table-text-bold } | La configuración o los consumibles no son adecuados. | Revisar el modo de color y el estado de los cartuchos. |
| **La pantalla está apagada** { .table-cl-secundario .table-text-bold } | El equipo está en modo de ahorro de energía. | Pulsar el botón indicado para volver a activarlo. |
| **El texto es demasiado pequeño** { .table-cl-secundario .table-text-bold } | Se han colocado demasiadas páginas por hoja. | Reducir el número de páginas por hoja. |
| **Se imprime más de lo necesario** { .table-cl-secundario .table-text-bold } | Se han seleccionado todas las páginas o demasiadas copias. | Cancelar el trabajo y revisar las páginas y el número de copias. |
