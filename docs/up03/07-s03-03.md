# S03.03 · Preparación e impresión de un documento

## ¿Qué vamos a hacer hoy?

Vamos a preparar un documento y a **imprimirlo en PDF**.

No usaremos papel. Usaremos una **impresora virtual**.

Haremos tres cosas:

1. Practicar con una guía paso a paso.

2. Hacer lo mismo en LibreOffice Writer.

3. Contestar una ficha y descargar un PDF con el resultado.

## ¿Qué debemos recordar?

Antes de imprimir:

- Mira qué impresora has elegido.

- Mira el tamaño y la orientación del papel.

- Mira la vista previa.

- Imprime solo lo necesario.

- Si sale un error, léelo antes de hacer nada.

- Si algo huele raro, apaga y avisa al profesor.

## Situación

Necesitamos una página informativa sobre tu evento.

Antes de imprimirla, revisaremos todas las opciones.

## Parte 1. Miramos las impresoras

En LliureX:

1. Abre **Configuración del sistema**.

2. Entra en **Impresoras**.

3. Mira qué impresoras hay.

Fíjate en:

- El nombre.

- Si es física o virtual.

- Si está preparada o tiene un error.

Lo contestarás en la ficha del final.

## Parte 2. Preparamos el documento

Abre **LibreOffice Writer** y crea un documento nuevo.

Escribe este texto:

---

**PRUEBA DE IMPRESIÓN**

Nombre y apellidos:  
Nombre del evento:  
Fecha:

Este documento se ha creado para comprobar el funcionamiento de la impresora y sus principales opciones. Antes de imprimir debemos revisar el tamaño del papel, la orientación, el número de páginas y la cantidad de copias.

Utilizar correctamente la impresora permite ahorrar papel, tinta y energía. También debemos comprobar el resultado y dejar el equipo preparado para la siguiente persona.

---

Ponle este formato:

1. Título centrado.

2. Título en negrita y de 18 puntos.

3. Nombre del evento en negrita.

4. Texto de 12 puntos.

5. Párrafos justificados.

6. Papel A4 y orientación vertical.

Guárdalo con el nombre:

`S03.03_Nombre_Apellido.odt`

## Parte 4. Generamos el PDF en Writer

Ahora hazlo de verdad en Writer.

1. Ve a **Archivo → Imprimir**.

2. Elige **Imprimir en un archivo** y el formato **PDF**.

3. Pon estas opciones:

| Opción { .table-main-column .table-content .table-bg-principal .table-cl-secundario } | Cómo debe quedar { .table-full-container .table-content .table-bg-principal .table-cl-secundario } |
|---|---|
| **Copias** { .table-cl-secundario .table-text-bold } | 1 |
| **Papel** { .table-cl-secundario .table-text-bold } | A4 |
| **Orientación** { .table-cl-secundario .table-text-bold } | Vertical |
| **Color** { .table-cl-secundario .table-text-bold } | Grises o blanco y negro |
| **Caras** { .table-cl-secundario .table-text-bold } | Una cara |

4. Mira la **vista previa**.

5. Guarda el archivo con el nombre:

   `S03.03_Nombre_Apellido.pdf`

6. Abre el PDF y comprueba que está bien.

## Parte 5. Contestamos la ficha

Ahora contesta la ficha. Tiene **6 pasos** y te dice al momento si has acertado:

1. Lo que has visto en LliureX.

2. El papel adecuado para cada trabajo.

3. Cómo ha quedado tu PDF.

4. Qué hacer si algo falla.

5. Imprimir con cabeza.

6. Descargar tu resultado.

Al final, escribe tu nombre y pulsa **Descargar mi resultado**.

Si terminas antes:

1. Abre otra vez **Archivo → Imprimir**.

2. Elige **dos páginas por hoja**.

3. Mira la vista previa.

4. Guarda otro PDF con el nombre:

   `S03.03_Ampliacion_Nombre_Apellido.pdf`
