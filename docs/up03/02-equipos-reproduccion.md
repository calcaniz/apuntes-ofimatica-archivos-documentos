# Equipos de reproducción de documentos

Los **equipos de reproducción** permiten obtener una o varias copias de un documento, una imagen o cualquier otro original.

Actualmente existen diferentes formas de reproducir información. La elección del sistema dependerá del tipo de original, del número de copias y de la calidad que necesitemos.

## Principales medios de reproducción

| Medio { .table-main-column .table-content .table-bg-principal .table-cl-secundario } | Descripción { .table-full-container .table-content .table-bg-principal .table-cl-secundario } |
|---|---|
| **Fotocopia** { .table-cl-secundario .table-text-bold } | Copia de un documento o una imagen realizada directamente sobre papel u otro soporte. |
| **Xerocopia** { .table-cl-secundario .table-text-bold } | Sistema de copia que utiliza un procedimiento electrostático para reproducir el original. Es el sistema empleado habitualmente por las fotocopiadoras. |
| **Fotografía** { .table-cl-secundario .table-text-bold } | Técnica que permite captar y conservar imágenes de la realidad mediante una cámara fotográfica o un dispositivo móvil. |
| **Facsímil** { .table-cl-secundario .table-text-bold } | Reproducción muy fiel de un documento, dibujo, libro o manuscrito original. |

## Instalación de los equipos

La ubicación de una impresora, fotocopiadora o escáner puede afectar a su funcionamiento y a su duración.

Debemos evitar colocar estos equipos en:

- Lugares expuestos directamente a la luz solar.

- Zonas con temperaturas demasiado altas o bajas.

- Espacios con mucho polvo o poca ventilación.

- Superficies inestables o expuestas a vibraciones.

- Lugares en los que se produzcan cambios bruscos de temperatura.

- Zonas cercanas al agua o a otros líquidos.

## Condiciones recomendadas

Para que los equipos funcionen correctamente, es recomendable instalarlos en un espacio que cumpla las condiciones siguientes:

| Condición { .table-main-column .table-content .table-bg-principal .table-cl-secundario } | Recomendación { .table-full-container .table-content .table-bg-principal .table-cl-secundario } |
|---|---|
| **Temperatura** { .table-cl-secundario .table-text-bold } | Mantener una temperatura estable, aproximadamente entre 10 y 20 °C. |
| **Humedad** { .table-cl-secundario .table-text-bold } | Evitar ambientes excesivamente secos o húmedos. |
| **Ventilación** { .table-cl-secundario .table-text-bold } | Colocar el equipo en una sala amplia y bien ventilada. |
| **Superficie** { .table-cl-secundario .table-text-bold } | Situar la máquina sobre una base resistente, estable y nivelada. |
| **Conexión eléctrica** { .table-cl-secundario .table-text-bold } | Instalar el equipo cerca de una toma de corriente segura y accesible. |
| **Espacio libre** { .table-cl-secundario .table-text-bold } | Dejar espacio alrededor del equipo para poder utilizarlo, abrirlo y realizar su mantenimiento. |

## El origen de la reproducción de documentos

Antes de la aparición de las máquinas actuales, los documentos se copiaban principalmente a mano. Este proceso era lento y dificultaba la difusión de la información.

En el siglo XV, **Johannes Gutenberg** desarrolló un sistema de impresión basado en tipos móviles. Este invento permitió producir muchas copias de un mismo documento con mayor rapidez y favoreció la difusión de libros y conocimientos.

La imprenta puede considerarse uno de los antecedentes de los equipos modernos de reproducción documental.
