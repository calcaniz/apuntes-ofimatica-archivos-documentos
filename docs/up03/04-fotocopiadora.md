# La fotocopiadora

Una **fotocopiadora** es una máquina que permite obtener una copia de un documento sobre papel u otro soporte adecuado.

Las fotocopiadoras actuales también pueden incorporar otras funciones:

- Imprimir documentos.

- Escanear textos e imágenes.

- Ampliar o reducir el original.

- Realizar copias a doble cara.

- Clasificar y grapar las copias.

- En algunos modelos, enviar documentos.

## Componentes de una fotocopiadora

Aunque existen diferentes modelos, la mayoría de las fotocopiadoras tienen los siguientes componentes:

|---|---|
| **Tapa de originales** { .table-cl-secundario .table-text-bold } | Mantiene el documento colocado sobre el cristal durante la copia. |
| **Cristal de exposición** { .table-cl-secundario .table-text-bold } | Superficie sobre la que se coloca el documento original. |
| **Alimentador de documentos** { .table-cl-secundario .table-text-bold } | Introduce automáticamente varias hojas para copiarlas o escanearlas. |
| **Panel de control** { .table-cl-secundario .table-text-bold } | Permite elegir el número de copias, el tamaño, el color y otras opciones. |
| **Bandejas de papel** { .table-cl-secundario .table-text-bold } | Guardan el papel que utilizará la máquina. |
| **Bandeja auxiliar** { .table-cl-secundario .table-text-bold } | Permite introducir manualmente papel especial o de otro tamaño. |
| **Bandeja de salida** { .table-cl-secundario .table-text-bold } | Recoge las copias realizadas. |
| **Cubierta delantera** { .table-cl-secundario .table-text-bold } | Permite acceder al interior para retirar papel atascado o cambiar consumibles. |

## Tipos de fotocopiadoras

Las fotocopiadoras pueden clasificarse según su tamaño, velocidad y capacidad de trabajo.

| Tipo { .table-main-column .table-content .table-bg-principal .table-cl-secundario } | Características { .table-full-container .table-content .table-bg-principal .table-cl-secundario } |
|---|---|
| **Personal** { .table-cl-secundario .table-text-bold } | Es pequeña y suele colocarse sobre una mesa. Está pensada para realizar pocas copias y normalmente utiliza papel A4. |
| **De oficina** { .table-cl-secundario .table-text-bold } | Tiene mayor velocidad y capacidad. Puede utilizar distintos tamaños de papel e incorporar varias bandejas y un alimentador automático. |
| **De alta producción** { .table-cl-secundario .table-text-bold } | Está preparada para realizar muchas copias. Puede imprimir a doble cara, clasificar, grapar, escanear y mejorar la calidad de las imágenes. |

La velocidad de una fotocopiadora se mide en **páginas por minuto**, que se representa mediante las siglas **ppm**.

## El tóner

El **tóner** es el consumible empleado para formar la imagen que aparecerá sobre el papel.

Puede presentarse principalmente de dos formas:

- **Tóner en polvo:** se introduce mediante un cartucho o depósito.

- **Tóner líquido:** se almacena en una botella o recipiente preparado para la máquina.

Cada fotocopiadora necesita un tipo de tóner concreto. Antes de sustituirlo, debemos comprobar que sea compatible con el modelo del equipo.

!!! importante "Uso responsable"
    No debemos abrir, golpear ni forzar los cartuchos. Para sustituir el tóner hay que seguir las instrucciones del fabricante y evitar tocar o derramar su contenido.

## Cómo realizar una fotocopia

### 1. Encender la fotocopiadora

1. Pulsa el interruptor principal.

2. Espera a que la máquina termine de arrancar.

3. Comprueba que el panel indique que está preparada.

4. Introduce el código de usuario si la máquina lo solicita.

### 2. Colocar el documento original

1. Abre la tapa.

2. Coloca el documento sobre el cristal de exposición.

3. Sitúa la cara que quieres copiar hacia abajo.

4. Alinea el documento con las marcas del cristal.

5. Cierra la tapa con cuidado.

!!! nota
    Si vas a copiar varias hojas, puedes utilizar el alimentador automático. Retira antes las grapas y los clips y comprueba que las hojas no estén dobladas.

### 3. Elegir el tamaño

Selecciona el tamaño del papel que vas a utilizar:

- A3.

- A4.

- A5.

También puedes seleccionar una **ampliación** o una **reducción** si quieres cambiar el tamaño del contenido.

### 4. Indicar el número de copias

Introduce el número de copias mediante el teclado del panel.

Si te equivocas, utiliza el botón **C**, **Borrar** o **Cancelar**, según el modelo de la máquina.

### 5. Configurar la copia

Antes de comenzar, comprueba las opciones seleccionadas:

| Opción { .table-main-column .table-content .table-bg-principal .table-cl-secundario } | Posibilidades { .table-full-container .table-content .table-bg-principal .table-cl-secundario } |
|---|---|
| **Color** { .table-cl-secundario .table-text-bold } | Blanco y negro o color. |
| **Caras** { .table-cl-secundario .table-text-bold } | Una cara o doble cara. |
| **Tamaño** { .table-cl-secundario .table-text-bold } | A3, A4, A5 u otro disponible. |
| **Escala** { .table-cl-secundario .table-text-bold } | Tamaño real, ampliación o reducción. |
| **Calidad** { .table-cl-secundario .table-text-bold } | Ajuste de claridad, oscuridad o densidad. |
| **Acabado** { .table-cl-secundario .table-text-bold } | Clasificación o grapado, si la máquina lo permite. |

### 6. Realizar la copia

1. Comprueba que la tapa esté cerrada.

2. Pulsa el botón **Copiar** o **Inicio**.

3. Espera a que termine el trabajo.

4. Utiliza el botón **Parar** o **Cancelar** si necesitas interrumpirlo.

### 7. Retirar los documentos

Cuando termine el proceso:

1. Recoge las copias de la bandeja de salida.

2. Comprueba que se han realizado correctamente.

3. Retira los documentos originales del cristal o del alimentador.

4. Deja la máquina preparada para la siguiente persona.

## El papel utilizado en la fotocopiadora

Las fotocopiadoras pueden trabajar con distintos tamaños de papel. Los más habituales pertenecen a la **serie A**.

| Tamaño { .table-main-column .table-content .table-bg-principal .table-cl-secundario } | Uso habitual { .table-full-container .table-content .table-bg-principal .table-cl-secundario } |
|---|---|
| **A3** { .table-cl-secundario .table-text-bold } | Carteles pequeños, planos, tablas o documentos de gran tamaño. |
| **A4** { .table-cl-secundario .table-text-bold } | Documentos, trabajos, cartas e informes. |
| **A5** { .table-cl-secundario .table-text-bold } | Folletos, notas, invitaciones o documentos pequeños. |

El formato A4 es el más utilizado en oficinas y centros educativos.

Cada tamaño de la serie A se obtiene dividiendo por la mitad el tamaño anterior. Por ejemplo, una hoja A3 equivale aproximadamente a dos hojas A4.

## Cómo cargar papel

Para colocar papel en la fotocopiadora debemos seguir estos pasos:

1. Comprueba el tamaño de papel que necesita la bandeja.

2. Extrae la bandeja hasta que quede abierta.

3. Separa y airea ligeramente las hojas para evitar que se peguen.

4. Coloca el papel dentro de la bandeja.

5. Ajusta las guías laterales al tamaño del papel.

6. No superes la marca que indica el límite máximo.

7. Introduce de nuevo la bandeja hasta el final.

8. Comprueba en el panel que la máquina reconoce el papel.

!!! warning "Antes de cargar papel"
    No utilices hojas arrugadas, húmedas, dobladas o con grapas. Podrían provocar un atasco o dañar la máquina.

## Incidencias frecuentes

Durante la utilización de una fotocopiadora pueden aparecer problemas sencillos. Antes de actuar, debemos leer el mensaje mostrado en el panel.

| Problema { .table-main-column .table-content .table-bg-principal .table-cl-secundario } | Posible causa { .table-content .table-bg-principal .table-cl-secundario } | Actuación { .table-full-container .table-content .table-bg-principal .table-cl-secundario } |
|---|---|---|
| **La máquina no se enciende** { .table-cl-secundario .table-text-bold } | El cable está desconectado o el interruptor está apagado. | Comprobar el cable y el interruptor principal. |
| **La pantalla está apagada** { .table-cl-secundario .table-text-bold } | La máquina está en modo de ahorro de energía. | Pulsar una tecla o tocar la pantalla para activarla. |
| **Las copias salen muy oscuras** { .table-cl-secundario .table-text-bold } | La densidad de imagen está demasiado alta. | Reducir la densidad o seleccionar una copia más clara. |
| **Las copias salen muy claras** { .table-cl-secundario .table-text-bold } | La densidad de imagen está demasiado baja o queda poco tóner. | Aumentar la densidad y comprobar el nivel de tóner. |
| **Falta una parte de la imagen** { .table-cl-secundario .table-text-bold } | El original está mal colocado o se ha elegido un tamaño incorrecto. | Colocar correctamente el original y revisar el tamaño del papel. |
| **El papel se atasca** { .table-cl-secundario .table-text-bold } | El papel está doblado, mal colocado o supera el límite de la bandeja. | Seguir las indicaciones del panel y retirar el papel con cuidado. |
| **No salen grapas** { .table-cl-secundario .table-text-bold } | El cartucho está vacío o existe una grapa atascada. | Reponer las grapas o seguir las instrucciones del manual. |
| **Aparece un aviso de tóner** { .table-cl-secundario .table-text-bold } | El cartucho está vacío o mal colocado. | Comprobar el cartucho y sustituirlo cuando sea necesario. |

!!! danger "Seguridad"
    No fuerces las tapas ni introduzcas las manos en zonas calientes. Si no puedes resolver una incidencia sencilla, detén el equipo y avisa al profesor o a la persona responsable.
