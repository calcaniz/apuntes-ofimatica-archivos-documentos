# Imprimir, exportar a PDF y conservar

## Imprimir el documento

1. Abrimos el documento y revisamos la previsualización.
2. Abrimos **Fitxer › Imprimeix…** (`Ctrl + P`).
3. Elegimos la impresora indicada.
4. Seleccionamos las páginas.
5. Dejamos **1** copia.
6. Pulsamos **Imprimeix** y recogemos el documento de la impresora.

## Comprobar el resultado

Con el papel en la mano revisamos que:

- el texto se lee bien;
- las imágenes tienen un tamaño adecuado;
- las tablas no están cortadas;
- los márgenes y la orientación son los indicados;
- no falta ninguna parte.

Si hay un error, primero corregimos el documento y averiguamos qué ha pasado. No volvemos a imprimir sin revisar.

## Exportar a PDF

Un **PDF** mantiene el aspecto del documento en cualquier ordenador o móvil. Es el formato adecuado para compartir o enviar un documento terminado.

1. Abrimos **Fitxer › Exporta com a › Exporta com a PDF…** (o el botón **PDF** de la barra de herramientas).
2. En la ventana **Opcions de PDF** pulsamos **Exporta**.
3. Elegimos la carpeta `PDF` de nuestro proyecto.
4. Escribimos el nombre y pulsamos **Guarda**.

!!! ejemplo "Dos archivos, dos usos"
    Documento editable: `Programa_Game_Vault.odt`

    Documento para compartir: `Programa_Game_Vault.pdf`

## ODT y PDF

| ODT { .table-main-column .table-content .table-bg-principal .table-cl-secundario } | PDF { .table-full-container .table-content .table-bg-principal .table-cl-secundario } |
|---|---|
| Se puede modificar con Writer. | Está preparado para leer, compartir o imprimir. |
| Es el archivo de trabajo. | Es la copia final. |
| Debemos conservarlo. | No sustituye al archivo original. |

Guardamos **los dos** archivos: si hay que cambiar algo, lo haremos en el ODT y volveremos a exportar el PDF.

## Organizar y conservar los documentos

Al terminar el proyecto, la carpeta debe quedar ordenada:

```text
Proyecto_Evento_Nombre
├── Documentos_Writer
│   └── Programa_evento_Nombre.odt
├── PDF
│   └── Programa_evento_Nombre.pdf
├── Imagenes
└── Copia_Seguridad
    └── Programa_evento_Nombre.odt
```

Para garantizar la **seguridad** y la **integridad** del trabajo:

- hacemos una copia de seguridad del ODT en otra ubicación;
- comprobamos que tanto el ODT como el PDF se abren correctamente;
- revisamos que el documento no contiene datos personales que no deban compartirse.
