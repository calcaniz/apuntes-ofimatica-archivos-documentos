# S02.02 · Damos formato a la tabla

## ¿Qué vamos a hacer hoy?

Hoy daremos **formato** a la tabla del programa para que se lea de un vistazo: encabezados destacados, datos bien alineados, bordes y filas alternas.

Lo haremos en tres partes:

1. Practicar con un **Writer virtual**, paso a paso.

2. Contestar una **ficha** y descargar un PDF con el resultado.

3. Dar formato a la tabla en **nuestro Writer**.

Aprenderemos a:

- Decidir qué datos se alinean a la izquierda y cuáles se centran.

- Destacar los encabezados.

- Elegir colores con buen contraste.

- Poner bordes a la tabla.

- Usar filas alternas.

## ¿Qué debemos recordar?

- Primero **seleccionamos** las celdas; después aplicamos el formato.

- Textos (actividades, lugares) a la **izquierda**; datos cortos (horas, días, números) **centrados**.

- Fondo oscuro, letra clara; fondo claro, letra oscura.

- Los bordes se cambian en **Taula › Propietats…**, pestaña **Vores**.

- El color de fondo de las celdas: botón **Color de fons de les cel·les de taula**.

## Situación

La tabla del programa de Lucía ya tiene todos los datos, pero no tiene bordes, los encabezados no destacan y las horas están alineadas como los textos. Vamos a dejarla clara y ordenada.

## Parte 1. Practicamos con el Writer virtual

La práctica tiene **5 pasos**:

1. Decide la alineación de cada tipo de dato.

2. Destaca los encabezados.

3. Alinea los datos.

4. Pon los bordes.

5. Colorea las filas alternas y guarda.

## Parte 3. Ahora, en tu Writer

Abre `Programa_evento_TuNombre.odt` y aplica este formato a la tabla:

| Parte { .table-main-column .table-content .table-bg-principal .table-cl-secundario } | Formato { .table-full-container .table-content .table-bg-principal .table-cl-secundario } |
|---|---|
| Fila del título { .table-cl-secundario .table-text-bold } | Negreta, centrada, tamaño 14 y un color de fondo |
| Encabezados { .table-cl-secundario .table-text-bold } | Negreta, centrados y un color de fondo con buen contraste |

Al terminar, guarda con `Ctrl + S`.

!!! importante "Comprueba antes de entregar"
    - [ ] Toda la tabla usa la misma fuente.
    - [ ] Los encabezados se leen bien sobre su color de fondo.
    - [ ] Las horas y los días están centrados; los textos, a la izquierda.
    - [ ] Se ven todos los bordes, con un grosor moderado.
    - [ ] La tabla cabe dentro de los márgenes.
