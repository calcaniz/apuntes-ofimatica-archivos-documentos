# S02.06 (22/10/2026)

## Preparamos el examen parcial

En esta sesión no aprenderemos herramientas nuevas.

Realizaremos una práctica completa para repasar las tablas, las imágenes y la corrección de documentos antes del examen parcial.

## ¿Qué vamos a hacer hoy?

Vamos a:

- Abrir y guardar un documento.
- Corregir errores.
- Aplicar formatos de texto.
- Crear y modificar una tabla.
- Insertar y colocar imágenes.
- Revisar el resultado final.

## ¿Qué debemos recordar?

Debemos leer todas las instrucciones antes de comenzar y trabajar en orden.

> Si no sabemos realizar un apartado, continuaremos con el siguiente y volveremos después.

---

# 1. Organización del trabajo

Seguiremos este orden:

1. Crear nuestra carpeta de trabajo.
2. Abrir el documento facilitado.
3. Guardarlo con el nombre indicado.
4. Corregir el texto.
5. Aplicar los formatos.
6. Crear la tabla.
7. Insertar las imágenes.
8. Revisar el documento.
9. Guardar los cambios.

---

# 2. Corrección del texto

El documento contendrá algunos errores que tendremos que localizar.

Debemos revisar:

- Faltas de ortografía.
- Palabras repetidas.
- Espacios dobles.
- Mayúsculas.
- Signos de puntuación.
- Tamaños de letra incorrectos.
- Formatos que no corresponden.

Podemos utilizar el corrector ortográfico mediante:

**Eines → Ortografia**

También podemos pulsar:

**F7**

---

# 3. Formato del documento

Aplicaremos el formato indicado en las instrucciones.

| Elemento { .table-main-column .table-full-container .table-content .table-bg-principal .table-cl-secundario } | Formato { .table-content .table-bg-principal .table-cl-secundario } |
|---|---|
| Título | Tamaño 18, negrita y centrado |
| Subtítulo | Tamaño 14, cursiva y centrado |
| Párrafos | Tamaño 12 y alineación justificada |
| Palabras importantes | Negrita o subrayado según las instrucciones |

---

# 4. Creación de la tabla

Crearemos una tabla siguiendo el modelo facilitado.

Debemos comprobar:

- El número de filas.
- El número de columnas.
- Los encabezados.
- La posición de los datos.
- La alineación.
- Los bordes.
- El color de fondo.

Los encabezados aparecerán:

- En negrita.
- Centrados.
- Con un color de fondo.

---

# 5. Inserción de imágenes

Insertaremos las imágenes indicadas mediante:

**Insereix → Imatge**

Después:

1. Cambiaremos su tamaño desde una esquina.
2. Elegiremos el ajuste.
3. Las colocaremos en la posición solicitada.
4. Comprobaremos que no tapen el texto.

La actividad incluirá:

- Una imagen centrada.
- Una imagen lateral con texto alrededor.

---

# 6. Guardar el documento

El archivo se guardará con el nombre indicado en la actividad.

Por ejemplo:

`S02.06_Nombre_Evento.odt`

Antes de cerrar Writer debemos pulsar:

**Ctrl + S**

Después:

1. Cerraremos Writer.
2. Localizaremos el archivo.
3. Volveremos a abrirlo.
4. Comprobaremos que los cambios están guardados.
