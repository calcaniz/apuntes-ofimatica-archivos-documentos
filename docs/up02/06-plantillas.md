# Plantillas

Una **plantilla** es un documento preparado que reutilizamos para crear otros documentos con el mismo formato. Puede contener márgenes, títulos, tipos de letra, colores, tablas, espacios para imágenes, encabezados y pies de página.

| Documento { .table-main-column .table-content .table-bg-principal .table-cl-secundario } | Plantilla { .table-full-container .table-content .table-bg-principal .table-cl-secundario } |
|---|---|
| Contiene la información definitiva. | Contiene una estructura que podemos reutilizar. |
| Se guarda como `.odt`. | Se guarda como `.ott`. |
| Lo modificamos para hacer el trabajo. | La conservamos para crear más documentos. |

## Abrir una plantilla

Cuando abrimos un archivo `.ott` (con doble clic o con **Fitxer › Obri…**), Writer **no abre la plantilla**: crea un documento nuevo **sin título** con su mismo contenido y formato. Así la plantilla original no se modifica.

La plantilla suele tener textos de ejemplo que indican qué debemos escribir:

- `NOMBRE DEL EVENTO`;
- `ESCRIBE AQUÍ EL LUGAR`;
- `FECHA Y HORA`;
- `INSERTA UNA IMAGEN`.

## Guardar el documento nuevo

Antes de hacer muchos cambios, guardamos el documento nuevo:

1. **Fitxer › Anomena i guarda…**
2. Elegimos nuestra carpeta.
3. Escribimos un nombre nuevo.
4. Comprobamos que el tipo es **Document de text ODF (.odt)**.
5. Pulsamos **Guarda**.

!!! ejemplo "De la plantilla al documento"
    Plantilla: `Plantilla_programa.ott`

    Documento nuevo: `Programa_KDD49_Valencia.odt`

## Sustituir el contenido

1. Seleccionamos el texto de ejemplo.
2. Escribimos nuestra información encima.
3. Comprobamos que se mantiene el formato.

Evitamos borrar títulos, tablas, imágenes decorativas, saltos de página, encabezados o pies de página que formen parte del modelo. Si borramos algo por error, `Ctrl + Z`.

## Mantener el formato

Al escribir sobre una plantilla conservamos el tipo de letra, los tamaños, los colores, las alineaciones, los bordes y la organización de la página. Solo cambiamos el formato si las instrucciones lo indican.

> El objetivo es cambiar el **contenido** sin desordenar la plantilla.

## Crear nuestra propia plantilla

Si hemos preparado un documento que queremos reutilizar, podemos guardarlo como plantilla con **Fitxer › Anomena i guarda…**, eligiendo el tipo **Plantilla de document de text ODF (.ott)**.
