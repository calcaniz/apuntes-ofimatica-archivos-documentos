# S02.10 (30/10/2026)

## Preparamos un documento para imprimir

Antes de imprimir debemos comprobar cómo quedará el documento en el papel.

En esta sesión utilizaremos la vista previa y configuraremos las principales opciones de impresión.

## ¿Qué vamos a hacer hoy?

Vamos a:

- Abrir la vista previa.
- Comprobar las páginas.
- Seleccionar la impresora.
- Elegir las páginas que se imprimirán.
- Indicar el número de copias.
- Revisar la orientación y el tamaño del papel.

## ¿Qué debemos recordar?

No debemos pulsar **Imprimir** sin revisar antes las opciones.

> Una impresión incorrecta consume papel, tinta y tiempo.

---

# 1. Vista previa de impresión

La vista previa permite comprobar cómo aparecerá el documento en el papel.

Podemos acceder mediante:

**Arxiu → Previsualització d'impressió**

Debemos revisar:

- El número de páginas.
- La posición del texto.
- Los márgenes.
- Las imágenes.
- Las tablas.
- Los posibles espacios en blanco.
- Los elementos que quedan cortados.

Si encontramos un problema, regresamos al documento y lo corregimos.

---

# 2. Abrir la ventana de impresión

Para abrir las opciones de impresión utilizamos:

**Arxiu → Imprimir**

También podemos utilizar:

**Ctrl + P**

Antes de continuar debemos comprobar qué impresora está seleccionada.

---

---

# 4. Seleccionar las páginas

Podemos imprimir:

- Todas las páginas.
- La página actual.
- Una página concreta.
- Un grupo de páginas.

## Ejemplos

Para imprimir solo la página 2:

`2`

Para imprimir las páginas 1, 2 y 3:

`1-3`

Para imprimir las páginas 1 y 3:

`1,3`

Debemos comprobar la selección antes de imprimir.

---

# 5. Número de copias

La opción **Copies** indica cuántos ejemplares se imprimirán.

Si necesitamos un documento, seleccionaremos:

`1 copia`

No debemos aumentar este número sin comprobarlo.

> Imprimir cinco copias por error desperdicia papel y tinta.

---

# 6. Orientación y papel

La orientación puede ser:

- **Vertical**, cuando la página es más alta que ancha.
- **Horizontal**, cuando la página es más ancha que alta.

El tamaño utilizado normalmente será:

**A4**

La orientación de impresión debe coincidir con la configuración del documento.
