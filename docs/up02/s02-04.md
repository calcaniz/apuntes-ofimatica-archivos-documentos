# S02.04 · Revisamos el texto y usamos una plantilla

## ¿Qué vamos a hacer hoy?

Hoy **revisaremos** el programa para que no tenga errores y aprenderemos a trabajar con **plantillas**: crear un documento a partir de una y guardar la nuestra.

Lo haremos en tres partes:

1. Practicar con un **Writer virtual**, paso a paso.

2. Contestar una **ficha** y descargar un PDF con el resultado.

3. Revisar el programa y crear nuestra plantilla en **nuestro Writer**.

Aprenderemos a:

- Usar el corrector ortográfico leyendo las sugerencias.

- Decidir cuándo corregir, ignorar o añadir al diccionario.

- Encontrar los errores que el corrector no ve.

- Crear un documento a partir de una plantilla `.ott`.

- Guardar el documento nuevo en formato ODT.

## ¿Qué debemos recordar?

- El corrector se abre con **Eines › Ortografia…** (`F7`).

- **Corregeix** para las faltas; **Afig al diccionari** solo para palabras correctas que Writer no conoce, como el nombre del evento.

- Las **Marques de formatació** (`Ctrl + F10`) muestran los espacios como puntos.

- Al abrir un `.ott`, Writer crea un documento **nuevo sin título**: la plantilla no cambia.

- El documento nuevo se guarda como **ODT**; una plantilla, como **OTT**.

4. Crea un documento desde la plantilla.

5. Guarda el documento nuevo.

## Parte 3. Ahora, en tu Writer

**A. Revisa el programa**

1. Abre `Programa_evento_TuNombre.odt`.

2. Pulsa `F7` y revisa cada palabra marcada: corrige las faltas y añade al diccionario el nombre de tu evento.

3. Activa las **Marques de formatació** (`Ctrl + F10`) y busca dobles espacios, espacios antes de comas o puntos, palabras repetidas e `Intro` de más.

4. Revisa también el formato: los títulos iguales, los párrafos con el mismo tamaño y nada en negrita por error.

5. Guarda con `Ctrl + S`.

**B. Crea tu plantilla**

1. Con el programa abierto, elige **Fitxer › Anomena i guarda…**

2. En **Tipus de fitxer**, elige **Plantilla de document de text ODF (.ott)**.

3. Nombre: `Plantilla_programa_` y tu nombre. Carpeta: `Documentos_Writer`. Pulsa **Guarda**.

4. Cierra el documento. Abre la plantilla con doble clic y comprueba que el título de la ventana dice **Sense títol**: Writer ha creado un documento nuevo y la plantilla no cambia.

5. Cierra ese documento sin guardar.

!!! importante "Comprueba antes de entregar"
    - [ ] El programa no tiene faltas de ortografía ni espacios dobles.
    - [ ] El nombre de tu evento no aparece subrayado en rojo.
    - [ ] Tienes `Plantilla_programa_TuNombre.ott` en `Documentos_Writer`.
    - [ ] Al abrir la plantilla, se crea un documento **Sense títol**.
