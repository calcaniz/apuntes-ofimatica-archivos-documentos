# S02.11 (04/11/2026)

## Imprimimos y conservamos documentos

En la sesión anterior preparamos las opciones de impresión.

En esta sesión imprimiremos una página, exportaremos el documento a PDF y guardaremos correctamente todos los archivos.

## ¿Qué vamos a hacer hoy?

Vamos a:

- Revisar el documento.
- Imprimir una página.
- Comprobar el resultado.
- Exportar una copia en PDF.
- Conservar el archivo original.
- Organizar los documentos.

## ¿Qué debemos recordar?

Antes de imprimir debemos comprobar:

- Impresora;
- Páginas;
- Copias;
- Orientación;
- Tamaño del papel.

> El archivo ODT permite seguir editando. El archivo PDF está preparado para compartir o imprimir.

---

# 1. Imprimir el documento

Para imprimir:

1. Abrimos el documento.
2. Revisamos la vista previa.
3. Seleccionamos **Arxiu → Imprimir**.
4. Elegimos la impresora indicada.
5. Seleccionamos la página.
6. Indicamos una copia.
7. Pulsamos **Imprimir**.

Después recogeremos el documento de la impresora.

---

# 2. Comprobar la impresión

Debemos revisar que:

- El texto pueda leerse;
- Las imágenes tengan un tamaño adecuado;
- Las tablas no estén cortadas;
- Los márgenes sean correctos;
- La orientación sea la indicada;
- No falte ninguna parte.

Si hay un error, primero corregiremos el documento.

No volveremos a imprimir sin revisar qué ha ocurrido.

---

# 3. Exportar a PDF

Para crear una copia en PDF podemos utilizar:

**Arxiu → Exportar com a -> Exportar com a PDF**

También podemos utilizar el botón PDF de la barra de herramientas.

Después:

1. Elegimos la carpeta.
2. Escribimos el nombre.
3. Pulsamos **Exportar**.

## Ejemplo

Documento editable:

`Programa_Game_Vault.odt`

Documento preparado para compartir:

`Programa_Game_Vault.pdf`

---

# 4. Diferencia entre ODT y PDF

| ODT { .table-main-column .table-full-container .table-content .table-bg-principal .table-cl-secundario } | PDF { .table-content .table-bg-principal .table-cl-secundario } |
|---|---|
| Se puede modificar con Writer. | Está preparado para leer, compartir o imprimir. |
| Conserva las herramientas de edición. | Mantiene la presentación del documento. |
| Es el archivo de trabajo. | Es la copia final. |
| Debemos conservarlo. | No sustituye al archivo original. |

Guardaremos los dos archivos.

---

# 5. Organizar los documentos

Dentro de nuestra carpeta podemos crear:

- Una carpeta para documentos editables;
- Una carpeta para archivos PDF;
- Una carpeta para imágenes.

## Ejemplo

    Mi_evento
    ├── Documentos
    │   └── Programa_evento.odt
    ├── PDF
    │   └── Programa_evento.pdf
    └── Imagenes
