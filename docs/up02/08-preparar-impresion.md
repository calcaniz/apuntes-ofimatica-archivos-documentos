# Preparar la impresión

Antes de imprimir comprobamos cómo quedará el documento en el papel y revisamos las opciones de impresión.

!!! importante "No imprimas sin revisar"
    Una impresión incorrecta consume papel, tinta y tiempo.

## La previsualización de impresión

La **previsualización** muestra el documento tal como saldrá en el papel. La abrimos con **Fitxer › Previsualització d'impressió** (`Ctrl + Mayús + O`).

Revisamos:

- el número de páginas;
- la posición del texto y los márgenes;
- las imágenes y las tablas;
- los espacios en blanco que sobran;
- los elementos que quedan cortados o pasan a otra página.

Si encontramos un problema, cerramos la previsualización, lo corregimos en el documento y volvemos a comprobar.

## La ventana de impresión

La abrimos con **Fitxer › Imprimeix…** (`Ctrl + P`). Lo primero es comprobar **qué impresora** está seleccionada.

| Opción { .table-main-column .table-content .table-bg-principal .table-cl-secundario } | ¿Para qué sirve? { .table-full-container .table-content .table-bg-principal .table-cl-secundario } |
|---|---|
| Impresora { .table-cl-secundario .table-text-bold } | Elegir el equipo que imprimirá el documento. |
| Páginas { .table-cl-secundario .table-text-bold } | Imprimir todo el documento o solo algunas páginas. |
| Copias { .table-cl-secundario .table-text-bold } | Indicar cuántos ejemplares se imprimirán. |
| Orientación { .table-cl-secundario .table-text-bold } | Vertical u horizontal. Debe coincidir con la del documento. |
| Tamaño del papel { .table-cl-secundario .table-text-bold } | Normalmente A4. |
| Doble cara { .table-cl-secundario .table-text-bold } | Imprimir por las dos caras, si la impresora lo permite. Ahorra papel. |

## Elegir las páginas

Podemos imprimir todas las páginas, la página actual o solo algunas. En la casilla de páginas escribimos:

| Escribimos { .table-main-column .table-content .table-bg-principal .table-cl-secundario } | Se imprime… { .table-full-container .table-content .table-bg-principal .table-cl-secundario } |
|---|---|
| `2` { .table-cl-secundario .table-text-bold } | Solo la página 2. |
| `1-3` { .table-cl-secundario .table-text-bold } | Las páginas 1, 2 y 3. |
| `1,3` { .table-cl-secundario .table-text-bold } | Las páginas 1 y 3. |

## El número de copias

Si necesitamos un solo ejemplar, dejamos **1** copia. No cambiamos este número sin comprobarlo: imprimir cinco copias por error desperdicia papel y tinta.
