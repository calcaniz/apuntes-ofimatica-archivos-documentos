# S02.04 (16/10/2026) 

## Insertamos y colocamos imágenes

Las imágenes ayudan a presentar y comprender la información de un documento.

En esta sesión aprenderemos a insertar una imagen, cambiar su tamaño y colocarla correctamente junto al texto.

## ¿Qué vamos a hacer hoy?

Vamos a:

- Buscar y guardar una imagen.
- Insertarla en Writer.
- Cambiar su tamaño.
- Colocarla en diferentes posiciones.
- Ajustar el texto alrededor de la imagen.

## ¿Qué debemos recordar?

Para modificar una imagen primero debemos seleccionarla.

> Cambiaremos su tamaño desde una esquina para evitar que quede deformada.

---

# 1. Buscar y guardar una imagen

Para guardar una imagen de Internet:

1. Buscamos una imagen relacionada con nuestro evento.
2. Pulsamos sobre ella con el botón derecho.
3. Seleccionamos **Anomena i guarda la imatge.**
4. Elegimos nuestra carpeta.
5. Escribimos un nombre adecuado.

## Ejemplo

En lugar de:

`imagen1.jpg`

Utilizaremos:

`moto_circuito.jpg`

Los formatos más habituales son:

- **JPG:** utilizado principalmente para fotografías.
- **PNG:** utilizado para logotipos, dibujos e imágenes con fondo transparente.

---

# 2. Insertar una imagen

Para insertar una imagen en Writer:

1. Colocamos el cursor en el lugar adecuado.
2. Seleccionamos **Insereix → Imatge**.
3. Buscamos la carpeta.
4. Seleccionamos la imagen.
5. Pulsamos **Obre**.

La imagen aparecerá dentro del documento.

---

# 3. Cambiar el tamaño

Para modificar el tamaño:

1. Seleccionamos la imagen.
2. Colocamos el ratón sobre una esquina.
3. Arrastramos hacia dentro o hacia fuera.

Si la imagen queda deformada utilizamos:

**Ctrl + Z**

Después volvemos a cambiar su tamaño desde una esquina.

---

# 4. Colocar la imagen

Una imagen puede colocarse de diferentes formas.

| Posición { .table-main-column .table-full-container .table-content .table-bg-principal .table-cl-secundario } | Resultado { .table-content .table-bg-principal .table-cl-secundario } |
|---|---|
| **Centrada** | Aparece separada del texto y en el centro de la página. |
| **Lateral izquierda** | La imagen queda a la izquierda y el texto a su derecha. |
| **Lateral derecha** | La imagen queda a la derecha y el texto a su izquierda. |
| **En línea** | La imagen se comporta como una letra dentro de una línea. |

---

# 5. Ajustar el texto

El ajuste determina cómo se coloca el texto alrededor de la imagen.

Para modificarlo:

1. Seleccionamos la imagen.
2. Pulsamos con el botón derecho.
3. Seleccionamos **Ajusta**.
4. Elegimos la opción indicada.

Para una imagen lateral utilizaremos un ajuste que permita colocar texto a su alrededor.

Para un icono pequeño utilizaremos:

**Àncora → Al caràcter**

---

# 6. Orden de trabajo

Cuando trabajemos con una imagen seguiremos este orden:

1. Buscar y guardar.
2. Insertar en Writer.
3. Cambiar el tamaño.
4. Elegir el ajuste.
5. Colocar la imagen.
6. Revisar el resultado.
7. Guardar el documento.
