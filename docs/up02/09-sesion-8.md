# S02.08 (28/10/2026)

## Trabajamos con plantillas

Una plantilla es un documento preparado que podemos reutilizar para crear otros documentos con el mismo formato.

En esta sesión utilizaremos una plantilla para crear un documento relacionado con nuestro evento.

## ¿Qué vamos a hacer hoy?

Vamos a:

- Abrir una plantilla.
- Reconocer sus partes.
- Sustituir los textos de ejemplo.
- Mantener el formato original.
- Insertar nuestros datos e imágenes.
- Guardar el resultado como un documento nuevo.

## ¿Qué debemos recordar?

No debemos borrar ni modificar el archivo original.

> Utilizaremos la plantilla para crear un documento nuevo.

---

# 1. ¿Qué es una plantilla?

Una plantilla es un modelo preparado que puede contener:

- Márgenes.
- Títulos.
- Tipos de letra.
- Colores.
- Tablas.
- Espacios para imágenes.
- Encabezados y pies de página.

La plantilla permite crear varios documentos con una presentación parecida.

| Documento { .table-main-column .table-full-container .table-content .table-bg-principal .table-cl-secundario } | Plantilla { .table-content .table-bg-principal .table-cl-secundario } |
|---|---|
| Contiene la información definitiva. | Contiene una estructura que podemos reutilizar. |
| Se guarda normalmente como ODT. | Puede guardarse como OTT. |
| Se modifica para realizar el trabajo. | Debe conservarse para crear más documentos. |

---

# 2. Abrir una plantilla

Para utilizarla una plantilla:

1. Localizamos el archivo.
2. Lo abrimos con Writer.
3. Observamos su estructura.
4. Identificamos qué elementos debemos cambiar.

La plantilla puede contener textos como:

- `NOMBRE DEL EVENTO`;
- `ESCRIBE AQUÍ EL LUGAR`;
- `INSERTA UNA IMAGEN`;
- `FECHA Y HORA`.

Estos textos indican qué información debemos introducir.

---

# 3. Sustituir el contenido

Para sustituir un texto:

1. Seleccionamos el texto de ejemplo.
2. Escribimos nuestra información.
3. Comprobamos que se mantiene el formato.

Debemos evitar borrar:

- Títulos necesarios.
- Tablas.
- Imágenes decorativas.
- Saltos de página.
- Encabezados.
- Pies de página.

Si eliminamos algo por error utilizamos:

**Ctrl + Z**

---

# 4. Mantener el formato

Al escribir sobre una plantilla debemos conservar:

- El tipo de letra.
- Los tamaños.
- Los colores.
- Las alineaciones.
- Los bordes.
- La organización de la página.

Solo cambiaremos el formato cuando las instrucciones lo indiquen.

> El objetivo es modificar el contenido sin desordenar la plantilla.

---

# 5. Guardar como documento nuevo

Antes de realizar muchos cambios utilizaremos:

**Arxiu → Anomena i desa**

Después:

1. Elegimos nuestra carpeta.
2. Escribimos un nombre nuevo.
3. Seleccionamos el formato ODT.
4. Pulsamos **Desa**.

## Ejemplo

Plantilla original:

`Plantilla_evento.ott`

Documento nuevo:

`Programa_KDD49_Valencia.odt`

De esta forma conservamos la plantilla original.
