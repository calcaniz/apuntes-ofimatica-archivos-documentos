# S02.01 (09/10/2026)

En las últimas sesiones hemos aprendido a introducir información mediante tablas y a insertar imágenes en un documento.

En esta sesión vamos a repasar estas herramientas y a utilizarlas juntas dentro de un mismo documento.

## ¿Qué vamos a hacer hoy?

Vamos a:

- Crear una tabla;
- Introducir información en sus celdas;
- Aplicar un formato básico a la tabla;
- Insertar imágenes;
- Cambiar su tamaño;
- Colocar las imágenes correctamente;
- Guardar y revisar el documento.

## ¿Qué debemos recordar?

Una tabla sirve para organizar información mediante **filas**, **columnas** y **celdas**.

Una imagen debe colocarse de forma que ayude a comprender el documento y no dificulte la lectura.

> Antes de cambiar una tabla o una imagen debemos seleccionarla.

## ¿Qué criterios vamos a trabajar?

- **CE03-e:** trabajar con tablas y aplicar formatos adecuados.
- **CE03-f:** integrar imágenes y otros objetos sencillos en el documento.

# 1. Las partes de una tabla

Una tabla está formada por filas, columnas y celdas.

- Las **filas** se distribuyen horizontalmente.
- Las **columnas** se distribuyen verticalmente.
- Las **celdas** son los espacios en los que escribimos la información.
- Los **encabezados** explican qué información contiene cada columna.

Por ejemplo:

| Actividad { .table-full-container .table-cl-secundario .table-bg-principal} | Lugar { .table-full-container .table-cl-secundario .table-bg-principal} | Hora { .table-full-container .table-cl-secundario .table-bg-principal} |
|---|---|---|
| Presentación | Salón principal | 16:00 |
| Competición | Zona de juego | 17:00 |
| Entrega de premios | Escenario | 18:30 |

La primera fila contiene los encabezados:

- Actividad.
- Lugar.
- Hora.

Las siguientes filas contienen los datos.

# 2. Crear una tabla en Writer

Para crear una tabla podemos utilizar:

**Taula → Insereix Taula**

También podemos utilizar el botón de tabla de la barra de herramientas.

Antes de crearla debemos saber:

1. Cuántas columnas necesitamos.
2. Cuántas filas necesitamos.
3. Qué información aparecerá en cada columna.

Por ejemplo, si necesitamos una fila de encabezados y cuatro filas de datos, crearemos una tabla de **cinco filas**.

> La fila de encabezados también cuenta como una fila de la tabla.

---

# 3. Escribir dentro de una tabla

Para escribir en una celda hacemos clic dentro de ella.

Podemos pasar a la siguiente celda utilizando la tecla:

**Tabulador**

También podemos movernos haciendo clic directamente en otra celda.

Debemos comprobar que:

- Cada dato está en la columna adecuada;
- No falta ninguna información;
- El texto no queda cortado;
- No hay filas vacías innecesarias.

---

# 4. Aplicar formato a una tabla

Podemos modificar el aspecto de una tabla para que resulte más fácil de leer.

## Encabezados

Los encabezados pueden aparecer:

- En **negrita**;
- Centrados;
- Con un color de fondo;
- Con un color de letra que pueda leerse correctamente.

## Bordes

Los bordes permiten distinguir las diferentes celdas.

Debemos comprobar que:

- Todos los bordes sean visibles;
- Las líneas no sean demasiado gruesas;
- La tabla mantenga un aspecto ordenado.

## Alineación

Podemos utilizar diferentes alineaciones:

- Los nombres y textos largos pueden quedar alineados a la izquierda.
- Los números, horas y datos breves pueden quedar centrados.

> No es necesario utilizar muchos colores. Un formato sencillo suele ser más fácil de leer.

---

# 5. Insertar una imagen

Para insertar una imagen utilizamos:

**Insereix → Imatge**

Después debemos:

1. Buscar la carpeta en la que está guardada.
2. Seleccionar la imagen.
3. Pulsar **Obre**.

La imagen aparecerá dentro del documento.

También podemos descargar una imagen relacionada con nuestro evento y guardarla primero en nuestra carpeta.

---

# 6. Cambiar el tamaño de una imagen

Para cambiar el tamaño:

1. Seleccionamos la imagen.
2. Colocamos el ratón sobre una de sus esquinas.
3. Arrastramos con cuidado.

Es importante modificarla desde una esquina para conservar sus proporciones.

> Si una imagen queda estirada o aplastada, debemos deshacer el cambio y volver a intentarlo.

Podemos deshacer la última acción utilizando:

**Ctrl + Z**

---

# 7. Colocar una imagen

Una imagen puede ocupar diferentes posiciones dentro del documento.

## Imagen centrada

La imagen aparece entre dos partes del texto y queda centrada en la página.

Es adecuada para:

- una imagen principal;
- una fotografía del evento;
- un logotipo;
- una imagen de presentación.

## Imagen lateral izquierda

La imagen se coloca a la izquierda y el texto continúa por su lado derecho.

## Imagen lateral derecha

La imagen se coloca a la derecha y el texto continúa por su lado izquierdo.

## Imagen en línea con el texto

La imagen se comporta como si fuera una letra o una palabra.

Esta opción resulta útil para:

- iconos;
- símbolos;
- imágenes pequeñas;
- elementos colocados junto a un título o eslogan.

---

# 8. El ajuste del texto

El ajuste determina cómo se coloca el texto alrededor de una imagen.

Podemos encontrar estas opciones pulsando con el botón derecho sobre la imagen.

Algunas posibilidades son:

- imagen separada del texto;
- texto alrededor de la imagen;
- imagen colocada delante o detrás del texto;
- imagen en línea con el texto.

Para las imágenes laterales debemos elegir un ajuste que permita que el texto aparezca a uno de sus lados.

> Una imagen demasiado grande puede mover el texto y desordenar el documento.

---

# 9. Combinar tablas e imágenes

Un documento puede contener texto, imágenes y tablas.

Por ejemplo, el documento de un evento puede tener:

1. Un título.
2. Una imagen principal.
3. Una explicación.
4. Una tabla con el horario.
5. Una imagen pequeña junto al eslogan.

Cada elemento cumple una función diferente:

- El texto explica.
- La imagen ayuda a identificar o comprender.
- La tabla organiza los datos.
