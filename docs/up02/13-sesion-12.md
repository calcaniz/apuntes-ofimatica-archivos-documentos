# S02.12 (05/11/2026)

## Preparamos la prueba final

En esta sesión realizaremos una práctica completa para preparar la prueba final de la unidad.

No aprenderemos herramientas nuevas.

## ¿Qué vamos a hacer hoy?

Vamos a:

- Utilizar una plantilla;
- Guardar un documento nuevo;
- Completar y revisar la información;
- Preparar la impresión;
- Exportar a PDF;
- Organizar y conservar los archivos.

## ¿Qué debemos recordar?

Debemos trabajar en orden y comprobar cada apartado antes de continuar.

> La plantilla original no debe modificarse.
---

# 1. Abrir y guardar la plantilla

Para comenzar:

1. Localizamos la plantilla.
2. La abrimos con Writer.
3. Utilizamos **Arxiu → Anomena i desa**.
4. Escribimos el nombre indicado.
5. Guardamos el nuevo documento en formato ODT.

## Ejemplo

Plantilla:

`Plantilla_programa.ott`

Documento nuevo:

`S02.12_Programa_Evento.odt`

---

# 2. Completar el documento

Sustituiremos los textos de ejemplo por la información de nuestro evento.

Debemos comprobar:

- Título.
- Subtítulo.
- Fecha.
- Lugar.
- Descripción.
- Imágenes.
- Tabla de actividades.

Mantendremos el formato de la plantilla siempre que las instrucciones no indiquen otra cosa.

---

# 3. Revisar el documento

Antes de imprimir comprobaremos:

- Ortografía.
- Tamaños de letra.
- Alineaciones.
- Imágenes.
- Tablas.
- Márgenes.
- Número de páginas.

Podemos utilizar:

**Eines → Ortografia**

o la tecla:

**F7**

---

# 4. Preparar la impresión

Abriremos:

**Arxiu → Imprimir**

Configuraremos las opciones indicadas.

| Opción { .table-main-column .table-full-container .table-content .table-bg-principal .table-cl-secundario } | Configuración del simulacro { .table-content .table-bg-principal .table-cl-secundario } |
|---|---|
| Impresora | La indicada por el profesor |
| Páginas | Una página concreta |
| Copias | 1 |
| Tamaño | A4 |
| Orientación | La utilizada en el documento |

Antes de imprimir revisaremos la vista previa.

---

# 5. Exportar a PDF

Después de preparar el documento:

1. Seleccionamos **Arxiu -> Exprtar com a -> Exportar como PDF**.
2. Elegimos la carpeta indicada.
3. Utilizamos el mismo nombre del documento.
4. Guardamos el archivo.

Debemos tener:

- Un archivo ODT;
- Un archivo PDF.
