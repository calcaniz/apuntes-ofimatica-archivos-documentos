# Un documento completo

Un documento profesional combina **texto**, **imágenes** y **tablas**. Cada elemento cumple una función:

- el **texto** explica;
- las **imágenes** ayudan a identificar y comprender;
- la **tabla** organiza los datos;
- el **formato** destaca la información importante.

## La estructura del programa del evento

| Parte { .table-main-column .table-content .table-bg-principal .table-cl-secundario } | Contenido { .table-full-container .table-content .table-bg-principal .table-cl-secundario } |
|---|---|
| Título { .table-cl-secundario .table-text-bold } | Nombre del evento. |
| Subtítulo { .table-cl-secundario .table-text-bold } | Una frase breve que lo describe. |
| Imagen principal { .table-cl-secundario .table-text-bold } | Una fotografía o el logotipo, centrada. |
| Introducción { .table-cl-secundario .table-text-bold } | Presentación del evento: qué es, dónde y cuándo. |
| Desarrollo { .table-cl-secundario .table-text-bold } | Actividades, normas o información principal, con una imagen lateral. |
| Tabla { .table-cl-secundario .table-text-bold } | Horario, actividades, participantes o resultados. |
| Eslogan { .table-cl-secundario .table-text-bold } | Frase final del evento. |

## Una guía de formato

Para que el documento tenga un aspecto uniforme, usamos siempre el mismo formato para los elementos del mismo tipo:

| Elemento { .table-main-column .table-content .table-bg-principal .table-cl-secundario } | Formato { .table-full-container .table-content .table-bg-principal .table-cl-secundario } |
|---|---|
| Título { .table-cl-secundario .table-text-bold } | Tamaño 18, negrita y centrado. |
| Subtítulo { .table-cl-secundario .table-text-bold } | Tamaño 14, cursiva y centrado. |
| Párrafos { .table-cl-secundario .table-text-bold } | Tamaño 12 y justificados. |
| Palabras importantes { .table-cl-secundario .table-text-bold } | Negrita. |
| Encabezados de la tabla { .table-cl-secundario .table-text-bold } | Negrita, centrados y con color de fondo. |
| Eslogan { .table-cl-secundario .table-text-bold } | Tamaño 14, negrita y centrado. |

!!! nota "Justificar un párrafo"
    La alineación **justificada** (botón **Justificat**) reparte el texto para que todas las líneas lleguen hasta los dos márgenes. Queda bien en párrafos largos; en títulos usamos la alineación centrada.

## Lista de comprobación

Antes de dar el documento por terminado comprobamos que:

- [ ] el texto no tiene faltas de ortografía ni espacios dobles;
- [ ] los títulos y los párrafos siguen la guía de formato;
- [ ] las imágenes están relacionadas con el evento, no están deformadas y no tapan el texto;
- [ ] la tabla tiene encabezados destacados, bordes visibles y los datos bien alineados;
- [ ] todo cabe dentro de los márgenes;
- [ ] el documento está guardado con un nombre significativo en la carpeta correcta.

## Guardar y comprobar

1. Pulsamos `Ctrl + S`.
2. Cerramos el documento.
3. Localizamos el archivo en su carpeta.
4. Lo volvemos a abrir.
5. Comprobamos que los cambios están guardados.

## Comprueba que lo has entendido

1. ¿Qué función cumple la tabla en el programa de tu evento?
2. ¿Por qué usamos siempre el mismo formato para todos los títulos?
3. ¿Qué alineación usarías para los párrafos? ¿Y para el título?
4. ¿Por qué cerramos y volvemos a abrir el documento al terminar?
