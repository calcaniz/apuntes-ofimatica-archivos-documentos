# S02.05 (21/10/2026)

## Corregimos un documento

Antes de entregar un documento debemos revisar el texto y corregir los posibles errores.

En esta sesión utilizaremos el corrector ortográfico de Writer y comprobaremos que el documento mantenga un formato uniforme.

## ¿Qué vamos a hacer hoy?

Vamos a:

- Localizar errores ortográficos.
- Utilizar las sugerencias de Writer.
- Corregir palabras manualmente.
- Revisar espacios, mayúsculas y signos.
- Detectar errores de formato.
- Guardar el documento corregido.

## ¿Qué debemos recordar?

Writer puede ayudarnos a localizar algunos errores, pero no puede comprobarlo todo.

> La revisión automática no sustituye una lectura final del documento.

---

# 1. El corrector ortográfico

Writer suele marcar las palabras que considera incorrectas mediante una línea roja.

Para corregir una palabra:

1. Pulsamos sobre ella con el botón derecho.
2. Revisamos las sugerencias.
3. Seleccionamos la palabra correcta.

Si ninguna sugerencia es adecuada, podemos corregirla manualmente.

> No debemos elegir la primera sugerencia sin leerla.

---

# 2. Revisar todo el documento

Podemos iniciar la revisión ortográfica utilizando:

**Eines → Ortografia**

También podemos utilizar la tecla:

**F7**

Writer mostrará las palabras que considera incorrectas y ofrecerá diferentes opciones.

Podemos:

- Cambiar la palabra;
- Ignorarla;
- Añadirla al diccionario;
- Continuar con la revisión.

Solo añadiremos una palabra al diccionario cuando estemos seguros de que está correctamente escrita.

# 4. Corregir errores de formato

También debemos revisar la presentación del documento.

Comprobaremos que:

- Los títulos tengan el mismo formato.
- Los párrafos utilicen el tamaño indicado.
- No aparezcan palabras en negrita por error.
- Las alineaciones sean correctas.
- No existan espacios innecesarios.
- Las imágenes no tapen el texto.
- Las tablas estén dentro de los márgenes.

Si encontramos un formato incorrecto, seleccionamos el texto y aplicamos el formato adecuado.

---

# 5. Deshacer un cambio

Si realizamos un cambio incorrecto podemos utilizar:

**Ctrl + Z**

Esta opción permite deshacer la última acción.

Si hemos deshecho algo por error podemos utilizar:

**Ctrl + Y**

> Debemos revisar el resultado después de deshacer o repetir una acción.

---

# 6. Guardar una copia

Antes de modificar un documento importante podemos crear una copia.

Utilizamos:

**Arxiu → Anomena i desa**

Por ejemplo:

- Documento original: `programa_evento.odt`
- Documento corregido: `programa_evento_corregido.odt`

De esta forma conservamos el archivo original.
