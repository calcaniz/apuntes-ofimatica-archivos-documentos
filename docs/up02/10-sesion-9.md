# S02.09 (29/10/2026)

## Creamos un documento completo

En esta sesión utilizaremos conjuntamente las herramientas aprendidas para crear un documento completo sobre nuestro evento.

No aprenderemos herramientas nuevas. Aplicaremos textos, formatos, imágenes y tablas dentro de un mismo documento.

## ¿Qué vamos a hacer hoy?

Vamos a crear un documento que incluya:

- Título y subtítulo.
- Varios párrafos.
- Formatos de texto.
- Imágenes.
- Una tabla.
- Una presentación clara y ordenada.

## ¿Qué debemos recordar?

Cada elemento debe cumplir una función:

- El texto explica.
- Las imágenes ayudan a comprender.
- La tabla organiza los datos.
- El formato destaca la información importante.

# 1. Estructura del documento

El documento tendrá estas partes:

| Parte { .table-main-column .table-full-container .table-content .table-bg-principal .table-cl-secundario } | Contenido { .table-content .table-bg-principal .table-cl-secundario } |
|---|---|
| Título | Nombre del evento |
| Subtítulo | Breve descripción |
| Introducción | Presentación del evento |
| Desarrollo | Actividades, normas o información principal |
| Imágenes | Fotografías relacionadas con el contenido |
| Tabla | Horario, participantes, resultados o actividades |
| Eslogan | Frase final del evento |

---

# 2. Formato del texto

Aplicaremos el siguiente formato:

| Elemento { .table-main-column .table-full-container .table-content .table-bg-principal .table-cl-secundario } | Formato { .table-content .table-bg-principal .table-cl-secundario } |
|---|---|
| Título | Tamaño 18, negrita y centrado |
| Subtítulo | Tamaño 14, cursiva y centrado |
| Párrafos | Tamaño 12 y justificados |
| Palabras importantes | Negrita |
| Eslogan | Tamaño 14, negrita y centrado |

---

# 3. Imágenes

El documento incluirá al menos dos imágenes:

- Una imagen principal centrada.
- Una imagen lateral con el texto alrededor.

Debemos comprobar que:

- Estén relacionadas con el evento.
- No estén deformadas.
- Queden dentro de los márgenes.
- No tapen el texto.
- Tengan un tamaño adecuado.

---

# 4. Tabla

Incluiremos una tabla relacionada con nuestro evento.

Puede representar:

- El horario.
- Las actividades.
- Los participantes.
- Los equipos.
- Las puntuaciones.
- Los resultados.

La tabla deberá tener:

- Encabezados en negrita.
- Encabezados centrados.
- Color de fondo.
- Bordes visibles.
- Datos correctamente alineados.

---

# 5. Guardar el documento

Utilizaremos un nombre relacionado con la sesión y el proyecto.

## Ejemplo

`S02.09_KDD49_Valencia.odt`

Antes de cerrar Writer:

1. Pulsamos **Ctrl + S**.
2. Cerramos el documento.
3. Localizamos el archivo.
4. Volvemos a abrirlo.
5. Comprobamos que los cambios están guardados.
