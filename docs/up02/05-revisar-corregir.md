# Revisar y corregir un documento

Antes de entregar un documento revisamos el texto y corregimos los errores. Writer puede ayudarnos, pero no lo detecta todo.

!!! importante "La última revisión la haces tú"
    El corrector automático no sustituye a una lectura final del documento.

## El corrector ortográfico

Writer subraya con una **línea roja ondulada** las palabras que considera incorrectas. Para corregir una:

1. Pulsamos sobre ella con el botón derecho.
2. Leemos las sugerencias.
3. Elegimos la palabra correcta, o la corregimos a mano si ninguna sirve.

No elegimos la primera sugerencia sin leerla.

## Revisar todo el documento

Con **Eines › Ortografia…** (`F7`) Writer recorre el documento y muestra cada palabra dudosa. Podemos:

| Botón { .table-main-column .table-content .table-bg-principal .table-cl-secundario } | ¿Qué hace? { .table-full-container .table-content .table-bg-principal .table-cl-secundario } |
|---|---|
| Corregeix { .table-cl-secundario .table-text-bold } | Cambia la palabra por la sugerencia elegida. |
| Ignora-ho una vegada { .table-cl-secundario .table-text-bold } | Deja la palabra como está y sigue. |
| Afig al diccionari { .table-cl-secundario .table-text-bold } | Guarda la palabra como correcta. Solo si estamos seguros, por ejemplo el nombre del evento. |

## Errores que debemos revisar

| Error { .table-main-column .table-content .table-bg-principal .table-cl-secundario } | Incorrecto { .table-content .table-bg-principal .table-cl-secundario } | Correcto { .table-full-container .table-content .table-bg-principal .table-cl-secundario } |
|---|---|---|
| Falta de ortografía { .table-cl-secundario .table-text-bold } | `competicion` | `competición` |
| Dos espacios { .table-cl-secundario .table-text-bold } | `el··evento` | `el evento` |
| Falta de mayúscula { .table-cl-secundario .table-text-bold } | `valencia racing cup` | `Valencia Racing Cup` |
| Signo mal colocado { .table-cl-secundario .table-text-bold } | `Hola , bienvenidos.` | `Hola, bienvenidos.` |
| Palabra repetida { .table-cl-secundario .table-text-bold } | `el evento evento` | `el evento` |

!!! tip "Ver los espacios"
    El botón **Marques de formatació** (`Ctrl + F10`) muestra los espacios como puntos y los finales de párrafo con el símbolo ¶. Así encontramos los espacios dobles y los `Intro` de más.

## Errores de formato

También revisamos la presentación:

- los títulos tienen todos el mismo formato;
- los párrafos tienen el tamaño indicado;
- no hay palabras en negrita por error;
- las alineaciones son correctas;
- las imágenes no tapan el texto;
- las tablas están dentro de los márgenes.

Si encontramos un formato incorrecto, seleccionamos el texto y aplicamos el formato adecuado.

## Desfés y Refés

| Atajo { .table-main-column .table-content .table-bg-principal .table-cl-secundario } | Acción { .table-full-container .table-content .table-bg-principal .table-cl-secundario } |
|---|---|
| `Ctrl + Z` { .table-cl-secundario .table-text-bold } | **Desfés**: anula la última acción. |
| `Ctrl + Y` { .table-cl-secundario .table-text-bold } | **Refés**: vuelve a aplicar lo que hemos deshecho. |

## Guardar una copia antes de corregir

Antes de modificar un documento importante, creamos una copia con **Fitxer › Anomena i guarda…**:

- original: `programa_evento.odt`;
- corregido: `programa_evento_corregido.odt`.

Así conservamos el archivo original por si lo necesitamos.
