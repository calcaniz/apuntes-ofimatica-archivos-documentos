# S04.04 · Que se entienda

## ¿Qué vamos a hacer hoy?

El catálogo del kiosco ya tiene todos los datos, pero cuesta leerlo. Hoy vamos a darle **formato** para que se entienda a la primera, y vamos a preparar la hoja **Compras**.

Lo haremos en tres partes:

1. Practicar con el **Calc virtual**, paso a paso.

2. Contestar una **ficha** y descargar un PDF con el resultado.

3. Dar formato a **nuestro archivo** del kiosco.

Aprenderemos a:

- Distinguir el contenido de una celda de su formato.

- Dar formato de moneda a los precios.

- Destacar los encabezados.

- Poner bordes a una tabla.

- Copiar el formato con **Clona el format**.

## ¿Qué debemos recordar?

- El formato cambia **cómo se ve** un dato, pero no su **valor**. En la barra de fórmulas vemos el valor real.

- Los precios llevan formato **Moneda**: **Format › Cel·les › Nombres › Moneda** (o **Ctrl + 1**), o el botón **€**.

- Una tabla debe ser **clara antes que llamativa**: encabezados destacados, pocos colores y bordes sencillos.

- **Clona el format** (el pincel) copia el aspecto de una celda sin copiar su contenido.

## Situación

Mañana enseñaremos el catálogo al resto del grupo. Tiene que verse claro: los precios en euros, los encabezados destacados y la tabla ordenada. Además, dejaremos lista la hoja **Compras** para calcular cuánto nos cuestan los productos.

## Parte 1. Practicamos con el Calc virtual

La práctica tiene **5 pasos**:

1. Une cada formato con su aspecto.

2. Pon los precios en euros.

3. Destaca los encabezados.

4. Ponle bordes a la tabla.

5. Copia el formato de los encabezados a la hoja Compras.

El Calc virtual te avisa si te equivocas. Puedes volver a intentarlo.

## Parte 3. Ahora, en tu Calc

1. **Prepara tu puesto**: espalda apoyada, pies en el suelo, pantalla enfrente y teclado cerca.

2. Abre tu archivo `Kiosco_FPB_Nombre.ods` y ve a la hoja **Productos**.

3. Selecciona los precios de venta (`D2:D11`) y aplica **Format › Cel·les › Nombres › Moneda**. Haz lo mismo con los precios de compra (`G2:G11`), esta vez con el botón **€**.

4. Selecciona los encabezados (`A1:G1`) y aplica **negrita**, un **color de fondo suave** y **centrado**.

5. Selecciona toda la tabla (`A1:G11`) y ponle **todos los bordes**.

6. Ve a la hoja **Compras** y prepara esta tabla copiando los datos desde **Productos** con **Ctrl + C** y **Ctrl + V**:

    | Columna { .table-main-column .table-content .table-bg-principal .table-cl-secundario } | Encabezado { .table-content .table-bg-principal .table-cl-secundario } | Datos que copias de Productos { .table-full-container .table-content .table-bg-principal .table-cl-secundario } |
    |---|---|---|
    | A { .table-cl-secundario .table-text-bold } | Producto | Los nombres (`B2:B11`) |
    | B { .table-cl-secundario .table-text-bold } | Unidades | Las existencias (`E2:E11`) |
    | C { .table-cl-secundario .table-text-bold } | Precio de compra | Los precios de compra (`G2:G11`) |
    | D { .table-cl-secundario .table-text-bold } | Coste | Vacía: la calcularemos en la próxima sesión |

7. Vuelve a **Productos**, pulsa `A1`, pulsa el pincel (**Clona el format**) y después selecciona `A1:D1` en **Compras** para que los encabezados se vean igual.

8. Ponle también **todos los bordes** a la tabla de **Compras** y ajusta el ancho de las columnas.

9. Guarda los cambios con **Ctrl + S**.

!!! importante "Comprueba antes de entregar"
    - [ ] Todos los precios se ven en euros, con dos decimales: `1,50 €`.
    - [ ] Los encabezados de las dos hojas están destacados de la misma manera.
    - [ ] Las tablas tienen bordes y se leen todos los textos.
    - [ ] La hoja **Compras** tiene los 10 productos, las unidades y los precios de compra.
    - [ ] Has guardado los cambios.
