# S04.03 · Códigos, logotipo y proveedor

## ¿Qué vamos a hacer hoy?

Hoy vamos a completar la hoja **Productos** del kiosco con datos que no se escriben a mano de cualquier manera: los **códigos** de los productos, los **precios de compra** que nos da el proveedor y el **logotipo** del kiosco.

Lo haremos en tres partes:

1. Practicar con el **Calc virtual**, paso a paso.

2. Contestar una **ficha** y descargar un PDF con el resultado.

3. Completar la hoja **Productos** en **nuestro Calc**.

Aprenderemos a:

- Elegir el periférico adecuado para cada dato.

- Usar el teclado numérico.

- Guardar los códigos como texto para que no pierdan cifras.

- Insertar una imagen sin deformarla.

- Abrir un archivo CSV y aprovechar sus datos.

## ¿Qué debemos recordar?

- Para usar el teclado numérico, la tecla **Bloq Num** debe estar activada.

- Los códigos no se usan para calcular: van con formato **Text**. Así no pierden el **0** inicial ni se ven como `8,41E+12`.

- Para cambiar el formato: selecciona la columna y usa **Format › Cel·les › Nombres › Text**.

- La imagen se inserta con **Insereix › Imatge** y se agranda con **Mayús** pulsada para que no se deforme.

- Al abrir un CSV, en **Importació de text** se marca el separador que usa el archivo.

## Situación

El proveedor del kiosco nos ha enviado su lista de productos con los **precios de compra**. Además, cada producto necesita un **código** para controlarlo, y el kiosco ya tiene **logotipo**.

## Parte 1. Practicamos con el Calc virtual

La práctica tiene **5 pasos**:

1. Une cada periférico con su uso.

2. Escribe precios con el teclado numérico.

3. Lee códigos de barras y dales formato de texto.

4. Inserta el logotipo sin deformarlo.

5. Abre el archivo del proveedor.

El Calc virtual te avisa si te equivocas. Puedes volver a intentarlo.

## Parte 3. Ahora, en tu Calc

Descarga estos dos archivos y guárdalos en la carpeta de la asignatura:

[Descargar logo_kiosco.png](../assets/up04/recursos/logo_kiosco.png){ .md-button download }
[Descargar proveedor.csv](../assets/up04/recursos/proveedor.csv){ .md-button download }

1. **Prepara tu puesto**: espalda apoyada, pies en el suelo, pantalla enfrente y teclado cerca.

2. Abre tu archivo `Kiosco_FPB_Nombre.ods` y ve a la hoja **Productos**.

3. Escribe **Código** en `F1` y **Precio de compra** en `G1`.

4. Pulsa la letra **F** para seleccionar toda la columna y aplica **Format › Cel·les › Nombres › Text**. Pulsa **D'acord**.

5. Escribe los códigos en la columna F. Usa el **teclado numérico** (con **Bloq Num** activado) para las cifras:

    | Producto { .table-main-column .table-content .table-bg-principal .table-cl-secundario } | Código { .table-full-container .table-content .table-bg-principal .table-cl-secundario } |
    |---|---|
    | Agua { .table-cl-secundario .table-text-bold } | 8410001000011 |
    | Zumo de naranja { .table-cl-secundario .table-text-bold } | 8410001000028 |
    | Refresco de cola { .table-cl-secundario .table-text-bold } | 0480001000035 |
    | Batido de cacao { .table-cl-secundario .table-text-bold } | 8410001000042 |
    | Bocadillo de tortilla { .table-cl-secundario .table-text-bold } | KIO-005 |
    | Bocadillo de jamón { .table-cl-secundario .table-text-bold } | KIO-006 |
    | Sándwich vegetal { .table-cl-secundario .table-text-bold } | KIO-007 |
    | Manzana { .table-cl-secundario .table-text-bold } | KIO-008 |
    | Galletas { .table-cl-secundario .table-text-bold } | 8410001000097 |
    | Barrita de cereales { .table-cl-secundario .table-text-bold } | 0480001000103 |

    Los bocadillos, el sándwich y la manzana no vienen envasados: les damos un **código propio** del kiosco.

6. Abre el archivo del proveedor con **Fitxer › Obri** y elige `proveedor.csv`. En la ventana **Importació de text**, deja marcado solo **Punt i coma** y pulsa **D'acord**.

7. En el archivo del proveedor, selecciona los precios de compra (`C2:C11`) y cópialos con **Ctrl + C**.

8. Vuelve a tu archivo del kiosco, pulsa la celda `G2` de la hoja **Productos** y pega con **Ctrl + V**. Después, cierra el archivo del proveedor sin guardar cambios.

9. Pulsa una celda vacía a la derecha de la tabla (por ejemplo, `I1`) e inserta el logotipo con **Insereix › Imatge**. Agrándalo arrastrando una esquina con **Mayús** pulsada.

10. Guarda los cambios con **Ctrl + S**.

!!! importante "Comprueba antes de entregar"
    - [ ] Los códigos se ven completos, también los que empiezan por **0**.
    - [ ] Los códigos están alineados a la **izquierda** (son texto).
    - [ ] Los precios de compra están en la columna G, alineados a la **derecha** (son números).
    - [ ] El logotipo se ve bien, sin deformar, y no tapa los datos.
    - [ ] Has guardado los cambios.
