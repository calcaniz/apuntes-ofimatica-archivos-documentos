# S04.06 · Fórmulas que se copian solas

## ¿Qué vamos a hacer hoy?

Hoy vamos a responder las grandes preguntas del kiosco: **¿cuánto hemos gastado?, ¿cuánto hemos ingresado?, ¿hemos ganado dinero?** Para ello usaremos **funciones** y aprenderemos a **fijar celdas** en las fórmulas.

Lo haremos en tres partes:

1. Practicar con el **Calc virtual**, paso a paso.

2. Contestar una **ficha** y descargar un PDF con el resultado.

3. Montar la hoja **Resumen** en **nuestro archivo** del kiosco.

Aprenderemos a:

- Distinguir referencias relativas, absolutas y mixtas.

- Fijar una celda con `$` (**Mayús + F4**).

- Usar las funciones `SUMA`, `MITJANA`, `MÀX`, `MÍN` y `COMPTA`.

- Tomar decisiones con la función `SI`.

## ¿Qué debemos recordar?

- `B2` es **relativa**: cambia al copiar. `$B$2` es **absoluta**: no cambia nunca.

- En LibreOffice Calc, **Mayús + F4** cambia el tipo de referencia mientras escribes la fórmula.

- En nuestro Calc las funciones están en **valenciano**: `SUMA`, `MITJANA` (media), `MÀX` (mayor), `MÍN` (menor) y `COMPTA` (contar).

- Las partes de una función se separan con **punto y coma**: `=SI(D2<5;"RECOMPRAR";"SUFICIENTE")`.

- Los textos de una fórmula van **entre comillas**.

## Situación

La jornada del kiosco ha terminado. Tenemos el coste de las compras y los ingresos de las ventas. Ahora hay que **resumirlo todo** en una hoja y saber qué productos hay que volver a comprar.

## Parte 1. Practicamos con el Calc virtual

La práctica tiene **5 pasos**:

1. Une cada tipo de referencia con lo que le pasa al copiarla.

2. Calcula el total de ingresos con `SUMA`.

3. Arregla una fórmula con una referencia absoluta.

4. Calcula la media, el mayor y el menor de los ingresos.

5. Decide qué hay que recomprar con la función `SI`.

El Calc virtual te avisa si te equivocas. Puedes volver a intentarlo.

Al terminar, escribe tu nombre y pulsa **Descargar el informe de la práctica**. El informe recoge el tiempo y los fallos de cada paso.

## Parte 3. Ahora, en tu Calc

1. **Prepara tu puesto**: espalda apoyada, pies en el suelo, pantalla enfrente y teclado cerca.

2. Abre tu archivo `Kiosco_FPB_Nombre.ods` y ve a la hoja **Ventas**.

3. Escribe **Total** en `C12` y, en `D12`, la fórmula `=SUMA(D2:D11)`. Comprueba que da **185,40 €**.

4. Escribe **% del total** en `E1`. En `E2` escribe `=D2/$D$12`, cópiala hasta `E11` y dale formato de **porcentaje** (botón **%**).

5. Añade tres columnas más en **Ventas**:

    | Columna { .table-main-column .table-content .table-bg-principal .table-cl-secundario } | Encabezado { .table-content .table-bg-principal .table-cl-secundario } | Qué contiene { .table-full-container .table-content .table-bg-principal .table-cl-secundario } |
    |---|---|---|
    | F { .table-cl-secundario .table-text-bold } | Existencias | Copia las existencias desde **Productos** (`E2:E11`) |
    | G { .table-cl-secundario .table-text-bold } | Quedan | `=F2-C2`, copiada hasta `G11` |
    | H { .table-cl-secundario .table-text-bold } | Estado | `=SI(G2<5;"RECOMPRAR";"SUFICIENTE")`, copiada hasta `H11` |

6. Ve a la hoja **Resumen** y prepara esta tabla. Para usar datos de otra hoja, escribe el principio de la fórmula, pulsa la pestaña de esa hoja, selecciona las celdas y pulsa **Intro**:

    | Celda { .table-main-column .table-content .table-bg-principal .table-cl-secundario } | Concepto (columna A) { .table-content .table-bg-principal .table-cl-secundario } | Fórmula (columna B) { .table-content .table-bg-principal .table-cl-secundario } | Resultado { .table-full-container .table-content .table-bg-principal .table-cl-secundario } |
    |---|---|---|---|
    | Fila 2 { .table-cl-secundario .table-text-bold } | Total de gastos | `=SUMA(` + rango `D2:D11` de **Compras** | 113,15 € |
    | Fila 3 { .table-cl-secundario .table-text-bold } | Total de ingresos | `=` + celda `D12` de **Ventas** | 185,40 € |
    | Fila 4 { .table-cl-secundario .table-text-bold } | Beneficio | `=B3-B2` | 72,25 € |
    | Fila 5 { .table-cl-secundario .table-text-bold } | Ingreso medio por producto | `=MITJANA(` + rango `D2:D11` de **Ventas** | 18,54 € |
    | Fila 6 { .table-cl-secundario .table-text-bold } | Producto que más ingresa | `=MÀX(` + rango `D2:D11` de **Ventas** | 35,00 € |
    | Fila 7 { .table-cl-secundario .table-text-bold } | Producto que menos ingresa | `=MÍN(` + rango `D2:D11` de **Ventas** | 7,70 € |
    | Fila 8 { .table-cl-secundario .table-text-bold } | Número de productos | `=COMPTA(` + rango `C2:C11` de **Ventas** | 10 |

7. Escribe **Concepto** en `A1` e **Importe** en `B1`. Da formato **Moneda** a `B2:B7`, copia el formato de los encabezados con **Clona el format** y ponle **todos los bordes** a la tabla.

8. Guarda los cambios con **Ctrl + S**.

!!! nota "Fórmulas con otras hojas"
    Al pulsar otra hoja mientras escribes la fórmula, Calc añade su nombre a la referencia, por ejemplo `=SUMA($Compras.D2:D11)`. Es correcto: así sabe de qué hoja son los datos.

!!! importante "Comprueba antes de entregar"

    - [ ] La hoja **Resumen** da un beneficio de **72,25 €**.
    - [ ] Ninguna celda muestra errores (`#DIV/0!`, `#NAME?`…).
