# 4. Sesión 3

## 4.1. ¿Qué es un procesador de textos?

Un procesador de textos es un programa que permite:

* Crear documentos
* Escribir y modificar textos.
* Corregir errores.
* Guardar y abrir documentos.
* Cambiar el aspecto del texto.
* Añadir imágenes y otros elementos.
* Imprimir el resultado.

En Lliurex utilizaremos **LibreOffice Writer** como procesador de textos.

## 4.2. Elementos básicos de Writer

Cuando abrimos Writer encontramos:

* **Página:** zona blanca en la que escribimos.
* **Cursor:** línea vertical que indica dónde aparecerá la siguiente letra.
* **Menús:** contienen las diferentes opciones del programa.
* **Barra de herramientas:** contiene botones para realizar las acciones más habituales.
* **Barra de estado:**  muestra información sobre el documento.

Para comenzar a escribir, hacemos clic sobre la página y utilizaremos el teclado.

## 4.3. Escribir correctamente

Cuando escribimos debemos recordar estas normas:

* Dejamos **un solo espacio** entre dos palabras.
* No podemos espacios antes de un punto o una coma.
* Después de un punto o una coma dejamos un espacio.
* Las frases empiezan por mayúscula.
* Los nombre propios también comienzan con mayúscula.
* Utilizaremos `Intro`solamente para comenzar un párrafo nuevo.
* No pulsaremos `Intro` al llegar al final de una línea (Writer cambia de línea automáticamente)

!!! example "Ejemplo correcto"
    El sábado se celebrará una carrera de coches. Los participantes deberán respetar las normas de seguridad.

!!! example "Ejemplo incorrecto"
    El sábado se celebrará una carrera de coches .Los participantes deberán respetar las normas de seguridad.

## 4.4. Teclas que utilizaremos

| Tecla { .table-main-column .table-cl-secundario .table-bg-principal } | Función { .table-full-container .table-cl-secundario .table-bg-principal }|
|---|---|
| `Espacio` | Separa dos palabras |
| `Intro` | Crea un párrafo nuevo |
| `Mayús` | Permite escribir una letra en mayúscula |
| `Retroceso` | Borra el carácter situado a la izquierda del cursor |
| `Suprimir` | Borra el carácter situado a la derecha del cursor |
| `Flechas` | Mueven el cursor por el documento |

Para escribir una letra mayúscula, mantenemos pulsada la tecla `Mayús` mientras escribirmos la letra.

## 4.5. Corregir un error

Si cometemos un error, no necesitamos borrar todo el texto:

1. Colocamos el cursor junto al error.
2. Borramos la letra o palabra incorrecta.
3. Escribimos el texto correcto.

También podemo utilizar la opción **Deshacer** para eliminar la última acción realizada.

> **Deshacer** no borra todo el documento, solamente anula la última acción.

## 4.6. Guardar el documento

Guardar permite conservar nuestro trabajo para continuar en otro momento.

Para guardar:

1. Pulsamos **Fitxer**->**Anomena i desa**
2. Seleccionamos la carpeta indicada.
3. Escribimos un nombre que permita reconocer el documento.
4. Pulsamos **Desa**

Debemos utilizar nombre claros y relacionados con el contenido

> **Ejemplo**
>
> `KDD49_Valencia_Carlos.odt`
>

La extensión .odt indica que se trata de un documento de LibreOffice Wirter

Después de guardarlo por primera vez, podemos pulsar el botón **Guardar** o utilizar `Ctrl + S` para conservar los últimos cambios.
