# El procesador de textos Writer

## ¿Qué es un procesador de textos?

Un **procesador de textos** es un programa que permite:

- crear documentos;
- escribir y modificar textos;
- corregir errores;
- cambiar el aspecto del texto;
- añadir imágenes, tablas y otros elementos;
- guardar, abrir e imprimir documentos.

En LliureX utilizaremos **LibreOffice Writer**. Con él podemos preparar cartas, invitaciones, carteles, horarios, informes o fichas.

## El cursor de escritura

El **cursor** indica el lugar exacto en el que aparecerá la siguiente letra que escribamos. Podemos moverlo:

- haciendo clic con el ratón en otro lugar del texto;
- utilizando las flechas del teclado.

!!! importante "Mira dónde está el cursor"
    Antes de escribir o borrar, comprobamos dónde está situado el cursor.
