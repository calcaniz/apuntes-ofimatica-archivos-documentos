# Resumen y preguntas finales

| Concepto { .table-main-column .table-content .table-bg-principal .table-cl-secundario } | Significado { .table-full-container .table-content .table-bg-principal .table-cl-secundario } |
|---|---|
| Archivo { .table-cl-secundario .table-text-bold } | Información guardada en el ordenador: un documento, una imagen, un PDF… |
| Carpeta { .table-cl-secundario .table-text-bold } | Sirve para guardar y organizar archivos y otras carpetas. |
| Extensión { .table-cl-secundario .table-text-bold } | Letras después del último punto del nombre. Indican el tipo de archivo: `.odt`, `.pdf`… |
| Ruta { .table-cl-secundario .table-text-bold } | Sucesión de carpetas que lleva hasta un archivo. |
| Mover / Copiar { .table-cl-secundario .table-text-bold } | Mover cambia el archivo de lugar; copiar crea otro igual. |
| Guarda / Anomena i guarda { .table-cl-secundario .table-text-bold } | Guarda actualiza el archivo; Anomena i guarda crea otro con otro nombre, lugar o formato. |
| Copia de seguridad { .table-cl-secundario .table-text-bold } | Copia de un archivo importante guardada en otro lugar para poder recuperarlo. |
| Confidencialidad { .table-cl-secundario .table-text-bold } | Solo las personas autorizadas pueden consultar cierta información. |
| Procesador de textos { .table-cl-secundario .table-text-bold } | Programa para crear, modificar, guardar e imprimir documentos de texto. |
| Cursor { .table-cl-secundario .table-text-bold } | Línea que indica dónde aparecerá la siguiente letra. |
| Párrafo { .table-cl-secundario .table-text-bold } | Bloque de texto que termina al pulsar `Intro`. |
| Formato { .table-cl-secundario .table-text-bold } | Aspecto del texto: fuente, tamaño, negrita, cursiva, subrayado… |
| Márgenes { .table-cl-secundario .table-text-bold } | Espacios en blanco entre el contenido y los bordes de la página. |
| Orientación { .table-cl-secundario .table-text-bold } | Posición de la página: vertical u horizontal. |
| Controladores de tamaño { .table-cl-secundario .table-text-bold } | Cuadrados que aparecen al seleccionar una imagen. |
| Tabla { .table-cl-secundario .table-text-bold } | Información organizada en filas, columnas y celdas. |

## Atajos de teclado de la unidad

| Atajo { .table-main-column .table-content .table-bg-principal .table-cl-secundario } | Acción { .table-full-container .table-content .table-bg-principal .table-cl-secundario } |
|---|---|
| `Ctrl + S` { .table-cl-secundario .table-text-bold } | Guardar |
| `Ctrl + Mayús + S` { .table-cl-secundario .table-text-bold } | Anomena i guarda |
| `Ctrl + O` { .table-cl-secundario .table-text-bold } | Abrir |
| `Ctrl + C` / `Ctrl + X` / `Ctrl + V` { .table-cl-secundario .table-text-bold } | Copiar / Cortar / Pegar |
| `Ctrl + Z` / `Ctrl + Y` { .table-cl-secundario .table-text-bold } | Desfés / Refés |
| `Ctrl + B` / `Ctrl + I` / `Ctrl + U` { .table-cl-secundario .table-text-bold } | Negrita / Cursiva / Subrayado |
| `Ctrl + F12` { .table-cl-secundario .table-text-bold } | Insertar una tabla |
| `Tab` / `Mayús + Tab` { .table-cl-secundario .table-text-bold } | Celda siguiente / anterior en una tabla |

## Preguntas finales

1. Escribe un nombre significativo para el cartel de tu evento. ¿Qué extensión tendrá?
2. ¿Qué diferencia hay entre mover y copiar un archivo?
3. ¿Cuándo usamos **Anomena i guarda** en lugar de **Guarda**?
4. ¿Dónde guardarías una copia de seguridad real? ¿Por qué?
5. Nombra tres datos personales que no deben aparecer en un documento compartido.
6. ¿Por qué no debemos pulsar `Intro` al final de cada línea?
7. ¿Qué hay que hacer antes de poner una palabra en negrita?
8. ¿Qué orientación y qué márgenes usarías para un horario?
9. ¿Cómo cambias el tamaño de una imagen sin deformarla?
10. ¿Cuántas filas tiene una tabla con una fila de encabezados y cinco filas de datos?
