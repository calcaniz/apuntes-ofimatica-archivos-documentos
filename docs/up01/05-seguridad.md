# Seguridad, integridad y confidencialidad

Los documentos pueden contener información importante o personal. Por eso debemos protegerlos.

| Concepto { .table-main-column .table-content .table-bg-principal .table-cl-secundario } | ¿Qué significa? { .table-full-container .table-content .table-bg-principal .table-cl-secundario } |
|---|---|
| Seguridad { .table-cl-secundario .table-text-bold } | Evitar que la información se pierda, se dañe o llegue a personas que no deberían tenerla. |
| Integridad { .table-cl-secundario .table-text-bold } | El documento está completo y su contenido no se ha modificado ni borrado por error. |
| Confidencialidad { .table-cl-secundario .table-text-bold } | Determinada información solo puede consultarla quien está autorizado. |

## Seguridad

Algunas medidas básicas de seguridad son:

- guardar los documentos en la carpeta correcta;
- hacer copias de los archivos importantes;
- no comunicar nuestras contraseñas;
- cerrar la sesión al terminar;
- no borrar archivos si no estamos seguros.

## Integridad

Para conservar la integridad de un documento:

- guardamos los últimos cambios;
- evitamos sobrescribir el archivo equivocado;
- comprobamos que el documento se abre correctamente;
- revisamos el documento antes de entregarlo.

## Confidencialidad

No debemos incluir en los documentos del evento ni compartir:

- contraseñas;
- el número completo del DNI;
- direcciones particulares;
- datos bancarios;
- información privada de otras personas.

!!! advertencia "Las contraseñas son secretas"
    No debemos comunicar nuestras contraseñas a compañeros, amistades ni personas desconocidas.

## Copias de seguridad

Una **copia de seguridad** es una copia de un archivo importante que conservamos para recuperarlo si el original se pierde, se borra o se estropea.

Para hacer una copia de seguridad en clase:

1. Seleccionamos el archivo original.
2. Lo copiamos (`Ctrl + C`).
3. Entramos en la carpeta `Copia_Seguridad`.
4. Pegamos el archivo (`Ctrl + V`).
5. Comprobamos que la copia se abre correctamente.

La copia no sustituye al original: conservamos los dos archivos.

!!! nota "Una copia de verdad está en otro sitio"
    Si el original y la copia están en el mismo dispositivo, podrían perderse los dos a la vez. Una copia de seguridad real debe guardarse en otra ubicación: una memoria USB, un disco externo, una carpeta de red del centro o un espacio seguro en la nube.

## Copia de seguridad o nueva versión

| Copia de seguridad { .table-main-column .table-content .table-bg-principal .table-cl-secundario } | Nueva versión { .table-full-container .table-content .table-bg-principal .table-cl-secundario } |
|---|---|
| Sirve para recuperar el archivo si ocurre un problema. | Sirve para conservar las diferentes etapas del trabajo. |
| Contiene la misma información que el original. | Contiene cambios o información nueva. |
| Se guarda en otra ubicación segura. | Puede guardarse junto al documento original. |
| Normalmente no se modifica. | Se utiliza para seguir trabajando. |
