# Guardar y abrir documentos

## Guardar por primera vez

Cuando guardamos un documento por primera vez debemos elegir:

- la **carpeta** donde lo guardaremos;
- el **nombre** del archivo;
- el **tipo** de archivo.

En LibreOffice Writer:

1. Abrimos el menú **Fitxer › Anomena i guarda…**
2. Entramos en la carpeta indicada, por ejemplo `Documentos_Writer`.
3. Escribimos un nombre significativo: `01_Datos_evento_Carlos`.
4. Comprobamos que el tipo es **Document de text ODF (.odt)**.
5. Pulsamos **Guarda**.

La extensión `.odt` indica que se trata de un documento de LibreOffice Writer.

## Guarda y Anomena i guarda

| Opción { .table-main-column .table-content .table-bg-principal .table-cl-secundario } | ¿Qué hace? { .table-full-container .table-content .table-bg-principal .table-cl-secundario } |
|---|---|
| **Fitxer › Guarda** (`Ctrl + S`) { .table-cl-secundario .table-text-bold } | Actualiza el archivo que tenemos abierto con los últimos cambios. |
| **Fitxer › Anomena i guarda…** (`Ctrl + Mayús + S`) { .table-cl-secundario .table-text-bold } | Crea otro archivo: con otro nombre, en otra carpeta, como una nueva versión o con otro formato. |

Después de guardar por primera vez, pulsaremos `Ctrl + S` a menudo mientras trabajamos:

- después de escribir un párrafo;
- después de hacer una corrección;
- antes de cerrar Writer.

!!! importante "Guarda antes de cerrar"
    Si cerramos Writer sin guardar, perderemos los últimos cambios. Si Writer pregunta si queremos guardar, leemos el mensaje antes de pulsar ningún botón.

## Localizar y abrir un archivo

Para volver a trabajar con un documento debemos recordar:

1. en qué carpeta lo hemos guardado;
2. qué nombre le hemos puesto;
3. qué tipo de archivo es.

Podemos abrirlo de dos maneras:

- entrando en su carpeta y haciendo **doble clic** sobre el archivo;
- desde Writer, con **Fitxer › Obri…** (`Ctrl + O`), buscando la carpeta y pulsando **Obre**.

## Versiones de un documento

Una **versión** es una nueva etapa del documento en la que hemos hecho cambios importantes. La versión anterior se conserva:

- `01_Datos_evento_Carlos.odt`
- `01_Datos_evento_Carlos_v2.odt`

Para crear una versión nueva abrimos el documento y utilizamos **Fitxer › Anomena i guarda…** con el nombre terminado en `_v2`.
