# Archivos, carpetas y extensiones

## Archivos y carpetas

Un **archivo** contiene información guardada en el ordenador. Puede ser un documento de texto, una hoja de cálculo, una presentación, una imagen o un PDF.

Una **carpeta** sirve para guardar y organizar archivos. Dentro de una carpeta también podemos crear otras carpetas, llamadas **subcarpetas**.

Podemos pensar en las carpetas como los archivadores de una oficina:

- el archivador sería la carpeta del proyecto;
- los separadores serían las subcarpetas;
- las hojas guardadas serían los archivos.

Una carpeta no es un documento: no se abre con Writer, Calc o Impress.

## Nombres de archivos significativos

El nombre de un archivo debe permitirnos saber qué contiene **sin necesidad de abrirlo**.

|---|---|
| `documento1.odt` { .table-cl-secundario .table-text-bold } | `01_Datos_evento_Carlos.odt` |
| `nuevo.odt` { .table-cl-secundario .table-text-bold } | `02_Invitacion_evento_Carlos.odt` |
| `trabajo_final_final2.odt` { .table-cl-secundario .table-text-bold } | `03_Cartel_evento_Carlos.odt` |

Para poner un buen nombre a un archivo:

- utilizamos palabras relacionadas con su contenido;
- añadimos un número cuando queremos indicar el orden;
- añadimos nuestro nombre cuando lo pide la actividad;
- separamos las palabras con guiones bajos: `01_Datos_evento_Carlos`;
- mantenemos siempre la misma forma de nombrar los archivos;
- evitamos nombres como `documento`, `trabajo`, `nuevo` o `copia`.

!!! importante "Caracteres que no debemos utilizar"
    Los nombres de archivo no pueden contener estos caracteres: `\ / : * ? " < > |`. Es mejor evitar también los acentos, la ñ y los espacios.

## La extensión de un archivo

La **extensión** son las letras que aparecen después del último punto del nombre. Indica el tipo de archivo y la aplicación con la que podemos abrirlo.

En el archivo `02_Invitacion_evento_Carlos.odt`:

- `02_Invitacion_evento_Carlos` es el nombre;
- `.odt` es la extensión.

| Extensión { .table-main-column .table-content .table-bg-principal .table-cl-secundario } | Tipo de archivo { .table-content .table-bg-principal .table-cl-secundario } | Aplicación { .table-full-container .table-content .table-bg-principal .table-cl-secundario } |
|---|---|---|
| `.odt` { .table-cl-secundario .table-text-bold } | Documento de texto | LibreOffice Writer |
| `.ods` { .table-cl-secundario .table-text-bold } | Hoja de cálculo | LibreOffice Calc |
| `.odp` { .table-cl-secundario .table-text-bold } | Presentación | LibreOffice Impress |
| `.pdf` { .table-cl-secundario .table-text-bold } | Documento preparado para consultar o imprimir | Visor de PDF |
| `.jpg` / `.png` { .table-cl-secundario .table-text-bold } | Imagen | Visor de imágenes |

!!! advertencia "No cambies la extensión"
    Si cambiamos o borramos la extensión sin querer, es posible que el archivo deje de abrirse. Al cambiar el nombre de un archivo, conservamos siempre su extensión.

## La ubicación y la ruta

La **ubicación** es el lugar donde está guardado un archivo. Para encontrar una casa necesitamos conocer su dirección; para encontrar un archivo necesitamos conocer su ubicación.

La sucesión de carpetas que hay que abrir para llegar a un archivo se llama **ruta**:

`Documents › Proyecto_Evento_Carlos › Documentos_Writer`

Dos archivos pueden tener el mismo nombre si están en carpetas diferentes. Por eso debemos fijarnos tanto en el **nombre** como en la **ubicación**.

## La carpeta de nuestro proyecto

En esta unidad organizaremos el trabajo así:

```text
Proyecto_Evento_Nombre
├── Documentos_Writer
├── Imagenes
└── Copia_Seguridad
```

- `Documentos_Writer` guarda los documentos que vamos creando.
- `Imagenes` guarda las imágenes que insertaremos en los documentos.
- `Copia_Seguridad` guarda las copias de los archivos importantes.
