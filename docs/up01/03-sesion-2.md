## 3.1. Archivos y carpetas

Como vimos en la sesión anterior, un **archivo** contiene información guardada en el ordenador.

Algunos ejemplos son:

* Un documento en Writer
* Una imagen
* Una presentación
* Una hoja de cálculo
* Un archivo PDF

Una **carpeta** sirve para guardar y organizar archivos y otras carpetas.

Podemos compararlo con una mochila:

* La carpeta sería la mochila.
* Los archivos serían los objetos que guardamos dentro.

Una carpeta no es un documento y no se abre con Writer, Calc o Impress.


## 3.2. Nombre de un archivo

Todos los archivos tienen un nombre. El nombre debe ayudarnos a reconocer su contenido.

Un nombre poco útil sería:

`documento1.odt`

Mejor llamarlo 

`01_Invitacion_evento_Carlos.odt`

Un buen nombre puede indicar:

* El número de la actividad.
* El contenido del archivo.
* El nombre de la persona que lo ha creado.

!!! salto-pagina-pdf ""

Debemos evitar nombres como:

* `nuevo.odt`
* `cosa.odt`
* `trabajo.odt`
* `documento_final_final2.odt`

También debemos evitar algunos caracteres especiales en los nombres:
 
`\ / :  * ? " < > | `


## 3.3. La extensión de un archivo

La  **extensión**son las letras que aparecen después del último punto del nombre.

En el archivo:

`04_Invitacion_evento_Carlos.odt`

* `04_Invitacion_evento_Carlos` es el nombre
* `.odt` es la extensión.

La extensión nos permite reconocer el tipo de archivo y el programa con el que podemos abrirlo.

| **Extensión** { .table-main-column .table-cl-secundario .table-bg-principal }  | **Tipo de archivo**  { .table-full-container .table-cl-secundario .table-bg-principal }  | **Aplicación** { .table-cl-secundario .table-bg-principal }|
|---|---|---|
| `.odt` | Documento de texto | LibreOffice Writer |
| `.ods` | Hoja de cálculo | LibreOffice Calc |
| `.odp` | Presentación | LibreOffice Impress |
| `.pdf` | Documento preparado para consultar o imprimir | Visor de PDF |

No debemos cambiar o borrar la extensión sin una indicación del profesor. Si la cambiamos incorrectamente, es posible que el archivo deje de abrirse.

## 3.4. La ubicación de un archivo

La **ubicación** es el lugar donde está guardado un archivo.

Para encontrar una casa necesitamos conocer su dirección. Para encontrar un archivo necesitamos conocer su ubicación.

Por ejemplo:

`Documentos -> Proyecto_Evento_Carlos -> Documentos_Writer`

Esta sucesión de carpeta se llama **ruta**

Dos archivos pueden tener el mismo nombre, pero encontrarse en carpetas diferentes. Por eso es importante fijarse tanto en el nombre como en la ubicación.

## 3.5. Operaciones con archivos

### Cambiar el nombre

Cambiar el nombre de un archivo nos permite identificar mejor su contenido.

Al cambiar el nombre debemos conservar su extensión.

Por ejemplo:

`documento1.odt`

puede convertirse en 

`04_Datos_evento_Carlos.odt`

### Mover

Mover significa cambiar un archivo de lugar

Cuando movemos un archivo:

* Desaparece de la carpeta original.
* Aparece en la nueva carpeta
* Solo continúa existiendo un archivo

Por ejemplo, podemos mover un documento desde `Descargas` hasta `Documentos_Writer`

!!! salto-pagina-pdf ""

### Copiar

Copiar significa crear otro archivo igual.

Cuando copiamos un archivo:

* El original permanece en su carpeta.
* Aparece una segunda copia en otra ubicación.
* Existen dos archivos iguales.

Podemos copiar un archivo en la carpeta `Copia_Seguridad` para evitar perder nuestro trabajo.

### Eliminar

Eliminar significa enviar un archivo o una carpeta a la papelera.

Antes de eliminar debemos comprobar:

1. Que hemos seleccionado el archivo correcto.
2. Que el archivo ya no es necesario.
3. Que no pertenece a otra persona

## 3.6. Diferencia entre mover y copiar

| Mover { .table-cl-secundario .table-bg-principal } | Copiar { .table-full-container .table-cl-secundario .table-bg-principal } |
|---|---|
| Cambia el archivo de lugar. | Crea otro archivo igual. | 
| El archivo deja de estar en la carpeta original. | El original continúa en su carpeta. |
| Sigue existiendo un solo archivo. | Existen el original y la copi. |

Si queremos organizar un archivo, normalmente lo **movemos**

Si queremos protegerlo frente a una pérdida, normalmente lo **copiamos**

## 3.7. Buscar un archivo

Si no sabemos dónde está un archivo, podemos utilizar el buscador del explorador de archivos.

Podemos buscar escribiendo:

* El nombre completo: `04_Datos_evento_Carlos.odt`
* Una parte del nombre: `evento`
* Una extensión: `.odt`

Para encontrarlo más fácilmente debemos:

1. Abrir la carpeta desde la que queremos buscar.
2. Pulsar en el buscador.
3. Escribir una palabra que aparezca en el nombre.
4. Esperar a que aparezcan los resultados.
5. Comprobar que es el archivo correcto.
6. Abrirlo para revisar su contenido.

Un archivo con un nombre significativo es mucho más fácil de encontrar.

## 3.8. La copia de seguridad

Una **copia de seguridad** es un copia de un archivo importante importante que guardamos en otro lugar.

La copia nos permite recuperar el trabajo si:

* Eliminamos el archivo original.
* Guardamos cambios incorrectos.
* El archivo deja de abrirse.
* No encontramos el documento original.

Para hacer una copia de seguridad:

1. Seleccionamos el archivo original.
2. Lo copiamos.
3. Entramos en la carpeta `Copia_Seguridad`.
4. Pegamos el archivo.
5. Comprobamos que la copia se puede abrir.

La copia de seguridad no debe sustituir al archivo original. Debemos conservar los dos archivos.

!!! salto-pagina-pdf ""

## 3.9. Seguridad y confidencialidad

Debemos guardar nuestros archivos de forma ordenada y segura.

No debemos incluir ni compartir:

* Contraseñas.
* Número del DNI.
* Dirección personal.
* Datos bancarios.
* Información privada de otras personas.

Tampoco debemos abrir, modificar, mover o eliminar los archivos de otros compañeros.

Cada persona debe trabajar en su propia carpeta y cuidar los documentos que ha creado.
