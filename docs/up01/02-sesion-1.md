## 2.1. Archivos y carpetas

Un **archivo** contiene información guardada en el ordenador. Puede ser un documento de texto, una hoja de cálculo, una presentación,, una imagen o un PDF.

Algunos ejemplos son:

* 01_Datos_evento_Carlos.odt
* Lista_participantes.ods
* Presentacion_evento.odp
* Cartel_evento.pdf

Una **carpeta** sirve para guardar y organizar archivos. Dentro de una carpeta también podemos crear otras carpetas, llamadas **subcarpetas**

Podemos pensar en las carpetas como los archivadores de una oficina:

* El archivo principal sería la carpeta del proyecto.
* Los separadores serían las subcarpetas.
* Los documentos guardados serían los archivos.

## 2.2. Nombres de archivos significativos

El nombre de un archivo debe permitirnos saber qué contiene sin necesidad de abrirlo.

Un nombre poco útil sería:

`documento1.odt`

Mejor llamarlo 

`01_Datos_evento_Carlos.odt`

!!! salto-pagina-pdf ""

Para poner un buen nombre a un archivo debemos:

* Utilizar palabras relacionadas con su contenido.
* Evitar nombres como `documento`, `trabajo`, `nuevo` o `copia`
* Mantener siempre una forma parecida de nombrar los archivos.
* Añadir nuestro nombre cuando sea necesario.
* Utilizar números para indicar el orden de los documentos.
* Evitar caracteres extraños en los nombres

Podemos separar las palabras mediante guiones bajos:

`01_Datos_evento_Carlos.odt`

## 2.3. La extensión de un archivo

La parte final del nombre se llama **extensión**. La extensión indica el tipo de archivo y la aplicación con la que podemos abrirlo.

## 2.4. Guardar y guardar como

Cuando creamos un documento por primera vez debemos elegir:

* El nombre del archivo
* La carpeta donde queremos guardarlo
* El tipo de archivo

En LibreOffice podemos utilizar:

* **Fitxer->Desa** para guardar los cambios realizados.
* **Fitxer->Anomena i desa...** para elegir otro nombre o guardar el documento en otra ubicación.

También podemos pulsar `Ctrl + S` para guardar rápidamente los cambios.

### 2.4.1. Guardar

La opción **Guardar** actualiza el archivo que tenemos abierto.

Por ejemplo, si añadimos una frase y pulsamos Guardar, la frase se incorpora al documento original.

### 2.4.2. Guardar como

La opción **Guardar como** permite crear otro archivo:

* Con un nombre diferente.
* En otra carpeta.
* Como una nueva versión.
* Con otro formato.

Antes de cerrar un documento debemos comprobar que hemos guardado los últimos cambios.

## 2.5. Localizar y abrir un archivo

Para volver a trabajar con un documento debemos recordar:

1. En qué carpeta lo hemos guardado.
2. Qué nombre le hemos puesto.
3. Qué tipo de archivo es.

Para abrirlo podemos entrar en su carpeta y hacer doble clic sobre el archivo.

Si utilizamos carpetas ordenadas y nombres significativos, encontraremos nuestros documentos con más facilidad.

## 2.6. Seguridad, integridad y confidencialidad

Los documentos pueden contener información importante o personal. Por ello debemos protegerlos.

### 2.6.1. Seguridad

La **seguridad** consiste en evitar que la información se pierda, se dañe o llegue a personas que no deberían tenerla.

Algunas medidas básicas de seguridad son:

* Guardar los documentos en la carpeta correcta.
* Realizar copias de los archivos importantes.
* No comunicar nuestras contraseñas.
* Cerrar nuestra sesión al terminar.
* No borrar archivos si no estamos seguros.
* Comprobar un documento antes de entregarlo.

### 2.6.2. Integridad

La **integridad** significa que el documento está completo y que su contenido no ha sido modificado o eliminado por error.

Para conservar la integridad debemos:

* Guardar los últimos cambios.
* Evitar sobreescribir el archivo equivocado.
* Comprobar que el documento que se abre correctamente.
* Conservar una copia de los archivos importantes.

!!! salto-pagina-pdf ""

### 2.6.3. Confidencialidad

La **confidencialidad** significa que determinada información solamente puede ser consultada por las personas autorizadas.

No debemos incluir en el documento del evento información como:

* Contraseñas.
* Número completo del DNI.
* Dirección particular.
* Datos bancarios.
* Información privada de otras personas.

!!! warning "Recuerda"
    **Las contraseñas son secretas. No debemos comunicarlas a compañeros, amistades ni personas desconocidas.**

## 2.8. Copias de seguridad

Una **copia de seguridad** es una copia un archivo que conservamos para poder recuperarlo si el original se pierde, se borra o se estropea.

En esta actividad simularemos una copia de seguridad guardando una copia del documento en el carpeta:

`Copia_Seguridad`

La copia tendrá un nombre diferente:

`01_Datos_evento_Carlos_copia.odt`

Una copia de seguridad real debería guardarse también en una ubicación diferente, por ejemplo:

* Una memoria USB.
* Una unidad externa.
* Un espacio seguro en la nube.
* Una carpeta de red del centro.

Si el original y la copia están en el mismo dispositivo, podrían perderse los dos al mismo tiempo.

## 2.9. Versiones de un documento

Una **versión** es una nueva etapa del documento en la que hemos realizado cambios.

Por ejemplo:

* `01_Datos_evento_Carlos.odt`
* `01_Datos_evento_Carlos_v2.odt`

La versión 2 puede contener nuevas ideas o modificaciones, mientras que la versión anterior se conserva.

| **Copia de seguridad** { .table-full-container .table-cl-secundario .table-bg-principal } | **Nueva versión** { .table-full-container .table-cl-secundario .table-bg-principal } |
|---|---|
| Se crea para recuperar el archivo si ocurre un problema | Se crea para conservar diferentes etapas del trabajo | 
| Normalmente contiene la misma información que el original | Contiene cambios o información nueva. |
| Debe guardarse en otra ubicación segura. | Puede guardarse junto al documento original. |
| No se modifica habitualmente. | Se utiliza para poder continuar trabajando |
