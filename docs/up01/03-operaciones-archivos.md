# Operaciones con archivos

Con el **explorador de archivos** podemos organizar nuestros documentos: cambiarles el nombre, moverlos, copiarlos, eliminarlos y buscarlos.

## Cambiar el nombre

Cambiar el nombre de un archivo nos permite identificar mejor su contenido.

1. Pulsamos con el botón derecho sobre el archivo.
2. Elegimos la opción para cambiar el nombre.
3. Escribimos el nombre nuevo **sin borrar la extensión**.
4. Pulsamos `Intro`.

Por ejemplo, `documento1.odt` puede convertirse en `01_Datos_evento_Carlos.odt`.

## Mover

**Mover** significa cambiar un archivo de lugar. Cuando movemos un archivo:

- desaparece de la carpeta original;
- aparece en la carpeta nueva;
- sigue existiendo **un solo** archivo.

Por ejemplo, podemos mover un documento desde `Baixades` hasta `Documentos_Writer`.

## Copiar

**Copiar** significa crear otro archivo igual. Cuando copiamos un archivo:

- el original permanece en su carpeta;
- aparece una copia en otra ubicación;
- existen **dos** archivos iguales.

| Mover { .table-main-column .table-content .table-bg-principal .table-cl-secundario } | Copiar { .table-full-container .table-content .table-bg-principal .table-cl-secundario } |
|---|---|
| Cambia el archivo de lugar. | Crea otro archivo igual. |
| El archivo deja de estar en la carpeta original. | El original continúa en su carpeta. |
| Sigue existiendo un solo archivo. | Existen el original y la copia. |
| Lo usamos para **organizar**. | Lo usamos para **proteger** el trabajo. |

## Eliminar

**Eliminar** significa enviar un archivo o una carpeta a la papelera. Antes de eliminar debemos comprobar que:

1. hemos seleccionado el archivo correcto;
2. el archivo ya no es necesario;
3. no pertenece a otra persona.

Mientras no vaciemos la papelera, podemos recuperar el archivo desde ella.

## Buscar un archivo

Si no sabemos dónde está un archivo, podemos utilizar el buscador del explorador de archivos:

1. Abrimos la carpeta desde la que queremos buscar.
2. Pulsamos en el buscador.
3. Escribimos una palabra del nombre: `evento`, `Invitacion` o la extensión `.odt`.
4. Esperamos a que aparezcan los resultados.
5. Comprobamos que es el archivo correcto antes de abrirlo.

Un archivo con un nombre significativo es mucho más fácil de encontrar.

## Atajos útiles

| Acción { .table-main-column .table-content .table-bg-principal .table-cl-secundario } | Atajo { .table-full-container .table-content .table-bg-principal .table-cl-secundario } |
|---|---|
| Copiar { .table-cl-secundario .table-text-bold } | `Ctrl + C` |
| Cortar (para mover) { .table-cl-secundario .table-text-bold } | `Ctrl + X` |
| Pegar { .table-cl-secundario .table-text-bold } | `Ctrl + V` |
| Cambiar el nombre { .table-cl-secundario .table-text-bold } | `F2` |
| Eliminar { .table-cl-secundario .table-text-bold } | `Supr` |

Los atajos no son obligatorios: también podemos realizar estas operaciones con el botón derecho del ratón.

!!! importante "Respeta el trabajo de los demás"
    No debemos abrir, modificar, mover ni eliminar los archivos de otras personas. Cada persona trabaja en su propia carpeta.
