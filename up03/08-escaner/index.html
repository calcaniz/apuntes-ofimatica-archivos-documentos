    El escáner

    Un escáner es un dispositivo que permite convertir un documento en papel, una fotografía o una imagen en un archivo digital.

    Este proceso se denomina digitalización.

    Una vez digitalizado, el documento puede:

    • Guardarse en el ordenador.

    • Organizarse dentro de una carpeta.

    • Enviarse por correo electrónico.

    • Subirse a Aules o a otro servicio.

    • Compartirse con otras personas.

    • Convertirse en un archivo PDF.

    • Imprimirse cuando sea necesario.

    Ventajas de la digitalización

    Ventaja Explicación
    Ahorro de espacio Los documentos digitales no necesitan archivadores ni espacio físico.
    Búsqueda rápida Los archivos pueden localizarse mediante su nombre o su carpeta.
    Acceso compartido Varias personas pueden consultar la información.
    Envío inmediato Los documentos pueden enviarse por correo o mediante una plataforma digital.
    Conservación Una copia digital ayuda a conservar documentos importantes.
    Reducción de papel No es necesario realizar una copia en papel cada vez que se consulta el documento.

    La digitalización no sustituye siempre al original

    Algunos documentos deben conservarse también en papel. No debemos destruir un original después de escanearlo sin recibir autorización.

    Componentes de un escáner

    Los componentes dependen del modelo, pero en un escáner de sobremesa encontramos habitualmente:

    Componente Función
    Tapa Mantiene el documento colocado y evita la entrada de luz exterior.
    Cristal de exposición Superficie sobre la que se coloca el documento.
    Panel de botones Permite iniciar o cancelar el escaneado.
    Fuente de luz Ilumina el documento durante el proceso.
    Sensor Recoge la luz reflejada y la convierte en información digital.
    Carro de escaneado Se desplaza por debajo del cristal para captar el documento.
    Alimentador automático Introduce varias hojas de forma automática, si el equipo dispone de él.
    Conexión Permite comunicar el escáner con el ordenador mediante USB, red o wifi.

    Organización de la digitalización

    Antes de comenzar a escanear una gran cantidad de documentos conviene preparar el trabajo.

    Debemos decidir:

    1. Qué documentos se van a escanear.

    2. Quién puede consultar los archivos.

    3. Qué nombre tendrá cada archivo.

    4. En qué carpeta se guardará.

    5. Qué formato se utilizará.

    6. Qué resolución necesitamos.

    7. Si los documentos originales deben conservarse.

    Una buena organización evita perder archivos o guardar varias veces el mismo documento.

    Tipos de escáner

    Escáner plano o de sobremesa

    Tiene una superficie de cristal sobre la que se coloca el documento.

    Es adecuado para:

    • Documentos sueltos.

    • Fotografías.

    • Tarjetas.

    • Documentos delicados.

    Es uno de los tipos más habituales en centros educativos y oficinas.

    Escáner con alimentador de hojas

    Introduce automáticamente varias páginas.

    Es adecuado para digitalizar:

    • Informes.

    • Facturas.

    • Formularios.

    • Documentos de varias páginas.

    Las hojas deben estar sueltas, tener un tamaño parecido y no contener grapas ni clips.

    Escáner para libros

    Permite digitalizar libros y documentos encuadernados sin presionarlos completamente contra un cristal.

    Suele utilizar una cámara colocada sobre el documento.

    Escáner portátil o manual

    Es pequeño y debe desplazarse sobre el documento.

    Puede utilizarse para digitalizar fragmentos de libros, recibos o imágenes pequeñas.

    El resultado depende de que el movimiento se realice correctamente.

    Escáner de tambor

    El documento se coloca sobre un cilindro que gira durante el escaneado.

    Ofrece una calidad elevada, pero es caro y se utiliza principalmente en trabajos profesionales.

    Escáner de gran formato

    Permite digitalizar documentos de gran tamaño, como:

    • Planos.

    • Mapas.

    • Carteles.

    • Diseños técnicos.

    Escáner para microfilm

    Se utiliza para digitalizar documentos almacenados en microfilm o microficha.

    Es un equipo especializado que suele encontrarse en archivos y bibliotecas.

    Teléfono móvil

    Un teléfono móvil puede utilizar su cámara como escáner mediante una aplicación.

    Estas aplicaciones pueden:

    • Detectar los bordes del documento.

    • Corregir la perspectiva.

    • Mejorar el contraste.

    • Unir varias páginas.

    • Crear un archivo PDF.

    Importante

    No debemos fotografiar ni escanear documentos personales de otras personas sin su autorización.

    Formatos de archivo

    Antes de escanear debemos elegir el formato adecuado.

    Formato Utilización
    PDF Es el formato más adecuado para documentos. Permite guardar varias páginas en un solo archivo.
    JPG o JPEG Es adecuado para fotografías e imágenes. Ocupa poco espacio, aunque puede perder algo de calidad.
    PNG Conserva bien la calidad y es adecuado para imágenes, capturas y documentos con texto.
    GIF Utiliza pocos colores y no suele ser la mejor opción para documentos escaneados.
    BMP Conserva mucha información, pero genera archivos de gran tamaño.
    TIFF Ofrece una calidad elevada y se utiliza en archivos y trabajos profesionales.

    Para una tarea de clase utilizaremos normalmente:

    • PDF para documentos de una o varias páginas.

    • JPG o PNG para fotografías o imágenes sueltas.

    Resolución

    La resolución indica la cantidad de puntos utilizados para formar una imagen digital.

    Se mide en puntos por pulgada, representados mediante las siglas ppp o dpi.

    Resolución Utilización
    150 ppp Documento sencillo que solamente se consultará en pantalla.
    200-300 ppp Documentos de texto y trabajos habituales.
    300-600 ppp Fotografías o documentos que necesitan más detalle.
    Más de 600 ppp Trabajos especializados. Genera archivos de gran tamaño.

    Para la mayoría de los documentos utilizaremos una resolución de 300 ppp.

    Nota

    Una resolución mayor produce más detalle, pero también genera un archivo más pesado. No debemos seleccionar la máxima resolución si no es necesaria.

    Modo de color

    El escáner también permite elegir cómo se captarán los colores:

    Modo Utilización
    Color Fotografías, carteles o documentos con información en color.
    Escala de grises Documentos sin color que contienen imágenes o diferentes tonos.
    Blanco y negro Documentos sencillos formados principalmente por texto.

    Cómo realizar un escaneo

    1. Preparar el documento

    Antes de comenzar:

    1. Retira las grapas y los clips.

    2. Comprueba que el documento no esté doblado ni arrugado.

    3. Ordena correctamente las páginas.

    4. Limpia con cuidado cualquier suciedad que pueda afectar al resultado.

    2. Colocar el documento

    En un escáner plano:

    1. Abre la tapa.

    2. Coloca el documento sobre el cristal.

    3. Sitúa la cara que quieres escanear hacia abajo.

    4. Alinea el documento con las marcas del cristal.

    5. Cierra la tapa.

    En un alimentador automático:

    1. Coloca las páginas ordenadas.

    2. Comprueba cuál es la cara que debe quedar hacia arriba.

    3. Ajusta las guías laterales.

    4. No superes el número máximo de hojas.

    3. Abrir el programa

    Abre la aplicación de escaneado instalada en LliureX o pulsa el botón correspondiente del equipo.

    El nombre del programa puede variar según el modelo de escáner.

    4. Configurar el escaneo

    Selecciona:

    • El modo de color.

    • La resolución.

    • El formato del archivo.

    • La carpeta de destino.

    • El nombre del archivo.

    • El tamaño del documento.

    5. Utilizar la vista previa

    Antes de guardar el documento, realiza una vista previa.

    Comprueba que:

    • El documento está recto.

    • No falta ninguna parte.

    • No aparecen bordes innecesarios.

    • La imagen tiene suficiente claridad.

    6. Digitalizar

    Pulsa Escanear o Digitalizar.

    Si el documento tiene varias páginas, continúa añadiéndolas antes de finalizar.

    7. Guardar y comprobar

    Guarda el archivo con un nombre que permita identificarlo.

    Ejemplo:

    Factura_2026_11_13.pdf

    Después:

    1. Abre el archivo.

    2. Comprueba todas las páginas.

    3. Verifica que el texto puede leerse.

    4. Confirma que está guardado en la carpeta correcta.

    Escaneado de documentos pequeños

    Para digitalizar una tarjeta, un recibo o un documento pequeño:

    • Utiliza preferentemente un escáner plano.

    • Coloca el documento recto sobre el cristal.

    • No utilices el alimentador automático.

    • Realiza una vista previa.

    • Recorta únicamente los bordes que no sean necesarios.

    • Comprueba que no falta ninguna parte del documento.

    Si el original es muy delicado, pide ayuda antes de colocarlo en el escáner.

    Incidencias frecuentes

    Problema Posible causa Actuación
    El escáner no se enciende El cable está desconectado o el interruptor está apagado. Comprobar la alimentación y el interruptor.
    El ordenador no reconoce el escáner Falta el controlador o existe un problema de conexión. Comprobar el cable, la red y el controlador instalado.
    No aparece la imagen No se ha utilizado correctamente el programa de escaneado. Abrir la aplicación adecuada y seleccionar el escáner.
    La imagen aparece torcida El documento está mal colocado. Colocar y alinear nuevamente el original.
    Falta una parte del documento El documento está fuera de la zona de escaneado. Ajustar su posición y realizar una vista previa.
    El resultado está borroso El cristal está sucio o la resolución es demasiado baja. Limpiar correctamente el cristal y revisar la resolución.
    El archivo ocupa demasiado Se ha utilizado una resolución excesiva o un formato inadecuado. Reducir la resolución o seleccionar PDF o JPG.
    Los colores son incorrectos El modo de color no es adecuado. Seleccionar color, escala de grises o blanco y negro según el original.
    El texto no puede leerse El original tiene poca calidad o se ha escaneado con poca resolución. Repetir el escaneado con una resolución adecuada.
    El alimentador atasca las hojas Hay hojas dobladas, grapas, clips o tamaños diferentes. Detener el proceso, retirar las hojas y prepararlas correctamente.

    Seguridad y confidencialidad

    No fuerces la tapa, el alimentador ni las piezas internas. Tampoco escanees documentos personales, médicos, académicos o administrativos sin autorización. Una vez terminada la tarea, comprueba que los archivos no quedan guardados en una carpeta pública.
